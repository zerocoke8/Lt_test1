# 효과음 (기획 13차)

> 상태: 설계 완료, 구현 대기 (12차 작업 뒤)
> 요청 원문: "그리고 일단 효과음들도 나중에 교체하더라도 다 넣어주고."
> 스킬 단계 이름 (`stage`)은 [skill-renewal.md](skill-renewal.md) 3장과 같다. 효과음은 리뉴얼된 스킬 기준.

---

## 1. 한 줄 요약

게임의 **모든 순간** (스킬 단계, 타격, 몬스터, 보스, 괴담 방, 돌발 괴담, UI 버튼)에 소리를 넣는다. 소리는 전부 **코드로 합성** (WebAudio, 파일 0개)해서 지금처럼 한 파일 아티팩트로 그대로 나가고, 나중에 `src/audio/files/<소리 id>.mp3`를 넣기만 하면 **그 소리만 진짜 파일로 바뀐다**. 폰은 첫 터치에서 소리가 켜지고, 일시정지 메뉴에서 음량·끄기를 고른다.

## 2. 구조

### 2-1. 어디에 무엇이 있나 (새 폴더 `src/audio/`, 화면 쪽 전용)

| 파일 | 하는 일 |
|---|---|
| `ids.ts` | 소리 id 목록 (`drag.${string}` 같은 묶음 형태라 새 캐릭터·새 단계를 빠뜨리면 타입 오류) + 묶음별 설정 (버스, 우선순위, 음량, 최소 간격, 동시 개수) |
| `synth/prims.ts` | 소리 재료: 톤 (파형, 음높이 미끄러짐), 노이즈 (흰·분홍·갈색 + 필터 스윕 + 떨림·알갱이), 종소리 (비정수 배음), FM, 클릭, 라이저, 왜곡·메아리·뒤집기·잔향 |
| `synth/voices.ts` | 캐릭터 목소리 표 `CHAR_VOICE[id] = {기준음, 재질, 화음 장/단/감/서스, 밝기}`. 펫·보스·괴담 방·돌발 괴담도 같은 표 |
| `synth/recipes.ts` | id → 소리 만드는 법. 캐릭터는 **역할 틀 5개** (탱커·근접·원거리·힐러·서포터) × 칸 (등장·일반·드래그·궁극기) 위에 **재질 덧칠** (강철·신성·사슬·칼날·피·그림자·바람·마법·화약·의료·부적·음악·시간·실)을 얹고, 리뉴얼 스킬의 단계마다 3장의 전용 소리를 더함 |
| `bake.ts` | 소리를 처음 쓸 때 한 번 미리 만들어 (OfflineAudioContext, 32kHz 모노) 저장. 자주 나는 소리는 3가지 변형. 전투 프레임 중에는 굽지 않고 쉬는 틈에 조금씩 (8ms 이하) |
| `manifest.ts` | 파일 교체 목록 (2-2) |
| `engine.ts` | AudioContext 하나, 버스 (UI·효과·주인공·배경 + 잔향), 덕킹, 리미터, 동시 재생 관리 |
| `director.ts` | 게임 이벤트 → 소리 (순수 함수 `route(events, state, prev, view)`라서 소리 없이 테스트 가능). 이벤트 종류가 늘면 타입 오류로 알림 |
| `settings.ts` | 음량·끄기 저장 (`swapTower.audio.v1`, localStorage, 막혀 있으면 기본값) |
| `uiSfx.ts` | 앱 맨 위 클릭 하나로 **모든 버튼**에 `ui.tap`. 버튼에 `data-sfx="<id>"`면 그 소리, `data-sfx=""`면 무음 |
| `index.ts` | `sfx` 하나. AudioContext가 없는 곳 (node, vitest, 서버)에서는 아무것도 안 함 |
| `devboard.ts` | 디버그 패널 "효과음" 칸: 모든 id를 묶음별로 ▶ 재생, 합성/파일 표시, 다시 굽기. `window.__proto.sfx = { play, ids, recent }` (최근 64개 기록) |

- `src/audio`는 `src/sim`, `src/net/protocol`, `server/`에서 절대 가져오지 않는다 (서버 묶음에 화면 코드가 섞이지 않게, 테스트로 막음).
- 서버 이벤트를 그대로 듣기만 하므로 **멀티 동기화를 새로 만들 필요가 없다**.
- 코드 크기 약 25~35KB. 구운 소리는 메모리에만 (보통 한 판 약 3MB, 전부 쓰면 8~10MB). 이번 판에 나온 캐릭터·펫·보스 것만 굽는다.

### 2-2. 나중에 진짜 파일로 바꾸는 법

1. 바꾸고 싶은 소리의 id를 디버그 패널 "효과음"에서 찾는다 (예: `drag.guardian.wave`).
2. `src/audio/files/drag.guardian.wave.mp3`로 넣는다. 끝. (`import.meta.glob`이 자동으로 찾고, 아티팩트 빌드는 파일을 한 HTML 안에 넣어 줌)
3. 음량을 맞추거나 변형 여러 개를 쓰려면 `manifest.ts`의 `SFX_MANIFEST`에 한 줄: `{ src: ['a.mp3','b.mp3'], gain: 0.8, rate: [0.96, 1.04], 출처, 라이선스 }`.

- 찾는 순서: ① 스킬 전용 파일 `skill.<skillId>` → ② id 파일 → ③ 그 id의 합성 레시피 → ④ 묶음 기본 합성음 (예: `drag._role.melee`) → ⑤ 무음 (콘솔에 debug 한 줄, 오류 아님).
- 파일을 못 읽으면 합성음으로 돌아감 (warn 한 번).
- 권장: **모노 mp3/m4a 96kbps**, 파일 전체 약 3MB까지 (아티팩트 한도 16MB, base64로 +33%). **ogg는 쓰지 않음** (옛 iOS Safari가 못 읽음). 파일마다 출처·라이선스를 manifest에 적음.

### 2-3. 폰에서 첫 터치로 소리 켜기

- 브라우저 규칙상 소리는 사용자가 **손을 뗄 때** (pointerup, touchend, click, keydown) 처음 켤 수 있다. 터치의 pointerdown은 안 됨 → 그래서 **pointerdown에 걸지 않는다**.
- 첫 손 뗌에서 AudioContext를 만들고 (이 전에는 만들지 않음 → 크롬 경고 0, "콘솔 오류 0" 규칙 유지) 아주 짧은 무음을 한 번 재생 (iOS 잠금 해제).
- 보통 편성 화면의 첫 탭에서 켜진다. 첫 동작이 카드 드래그여도 놓는 순간 켜지고, 착지 소리는 0.12초 뒤에 나므로 빠지지 않는다.
- 전화·블루투스 전환으로 소리가 멈추면 (`interrupted`) 다시 첫 터치를 기다린다.
- iOS 17+: `navigator.audioSession.type = 'ambient'` → **무음 스위치를 따르고, 듣던 음악을 끊지 않음**. 무음 모드 폰에서는 소리가 안 나는 것이 정상 (7번 확인 항목).

### 2-4. 음량·끄기

- 일시정지 메뉴: 🔊/🔇 토글 + 슬라이더 3개 (전체, 효과음, 배경음). 편성 화면 오른쪽 위에 작은 🔊 토글.
- 기본값: 전체 0.8, 효과음 1.0, UI 0.7, 배경음 0.35, 켜짐. 저장됨.
- 끄기는 0.05초에 0으로 내림 (멈추지 않음 → 다시 켜면 바로 나옴).
- 주소에 `?mute=1`이면 강제로 끔 (자동 테스트·녹화용, `recent` 기록은 계속됨).

### 2-5. 시간 맞추기와 일시정지

- 모든 소리는 `ctx.currentTime + 지연`으로 예약 (setTimeout 안 씀 → 프레임이 밀려도 안 어긋남).
- 스킬의 지연·간격 (sim 초)은 `gameSpeed`로 나눔 (디버그 2×/4×).
- 드래그 착지 소리는 `DASH_LAND` (0.12초, `src/render/dashtime.ts`) 뒤 → 화면의 착지·멈춤과 같은 순간.
- 솔로 일시정지·세로 화면 → 소리 정지 (예약된 소리도 멈춤). 멀티 메뉴는 게임이 계속 돌므로 **멈추지 않음**. 탭이 가려지면 정지.
- 보상·괴담 화면 (전투 멈춤): 전투 반복음은 0.3초에 꺼지고 배경음이 괴담 드론으로 바뀜.

### 2-6. 기존 코드에 붙이는 곳 (작게)

| 파일 | 붙이는 것 |

## 4. 섞는 규칙

### 4-1. 크기 (리미터 앞 최고 크기)

| 크기 | 소리 |
|---|---|
| −3dB | 내 궁극기 |
| −5dB | 내 드래그 큰 박자, 보스 페이즈·등장, 승리·패배 |
| −8dB | 보스·중형보스 준비·떨어짐 |
| −13dB | 다른 플레이어의 드래그·궁극기 |
| −14dB | 일반스킬, UI (−14~−18) |
| −16dB | 타격 4개 이상 뭉친 소리 |
| −20dB | 타격 하나 |
| −28~−30dB | 배경음 |

마지막에 리미터 (−10dB 문턱, 빠른 어택)가 있어서 많이 겹쳐도 깨지지 않는다.

### 4-2. 동시에 너무 많을 때

- **우선순위** 5 (내 궁극기, 승리·패배·탈락, 보스 페이즈, 그로기 시작) > 4 (내 드래그, 보스 패턴, 끊김!, 돌발 괴담, 내 캐릭터 쓰러짐, 궁극기 준비, 괴담 결과, 보상 고름) > 3 (다른 사람 드래그·궁극기, 중형보스, 광폭화, 층 시작·클리어, UI 확인·거절, 내 펫) > 2 (일반스킬, 상태, 치명, 큰 회복, 몹 준비·떨어짐, 돌진, 등장) > 1 (타격, 기본 공격, 피격, 몹 등장·죽음, 작은 회복, 틱) > 0 (배경·알림).
- **동시 최대 24개** (코어 4개 이하 폰은 16개). 넘치면 우선순위가 같거나 낮은 가장 오래된 소리를 0.015초에 줄이고 새 소리를 냄, 아니면 새 소리를 버림.
- 묶음별 동시 개수: 타격 6, 몹 죽음 4, UI 4, 틱 2, 반복음은 하나씩 (반복음 전체 3개).
- **같은 소리 최소 간격**: 기본 타격 45ms, 스킬 타격 60ms, 치명 70ms, 약점 80ms, 보스 타격 100ms, 피격 150ms, 작은 회복 200ms, 기본 공격 90~120ms (소스마다), 몹 죽음 60ms, 몹 등장 100ms, 소환 예고 250ms, 카드 준비 300ms.
- 한 프레임에 같은 종류 N개 → **하나로** 재생, 크기 × (1 + 0.35·log2 N) (최대 ×2). 4개 이상이면 `.multi` (뭉친 소리)로 바꿈.
- 지겹지 않게: 자주 나는 소리는 변형 3개 + 재생 속도 ±4% + 크기 ±1.5dB 무작위.
- 끊긴 뒤 몰려온 이벤트: 0.25초보다 오래된 묶음은 우선순위 4 이상만 냄 (재연결·멈칫한 뒤 폭주 방지).

### 4-3. 내 소리와 다른 플레이어 소리 (멀티)

| | 나 | 다른 플레이어·봇 |
|---|---|---|
| 드래그·궁극기 | 전체 레시피, 주인공 버스 (덕킹 안 받음), 라이저 포함 | **멀리 버전**: −8dB + 3.5kHz 로우패스, 라이저 없음, 궁극기는 0.8초 마무리 + 꼬리만, 연타 4번까지, 덕킹을 일으키지 않음. 다른 사람 궁극기는 한 번에 하나만 |
| 일반스킬·기본 공격·펫·궁극기 준비·카드 준비 | 냄 | **안 냄** |
| 쓰러짐 | `char.down` | `char.down.far` |
| 몬스터·보스·돌발 괴담·층 이벤트 | 모두에게 같은 크기 | 같음 |

- 타격 이벤트에는 때린 플레이어가 없어서, "내 타격"은 최근 내 스킬 이름 / 내 유닛이 때린 것으로 추정한다 (`vfx.myNames`와 같은 방법). 나머지는 공용 제한만 받는다.

### 4-4. 덕킹 (큰 소리가 날 때 다른 소리를 잠깐 줄임)

| 언제 | 무엇을 | 얼마나 |
|---|---|---|
| 내 궁극기 컷인 | 효과 버스 −8dB (0.04초에 내려가 1.2초 유지, 0.4초에 복귀), 배경 −14dB, 다른 사람 일반·기본 공격 소리 끔 | 주인공 버스·UI는 그대로 |
| 크로노 시간 정지 | 효과 버스 로우패스 (300Hz로 0.25초 → 정지 동안 1200Hz) | 끝날 때 0.3초에 풀림 |
| 내 드래그 큰 박자 | 효과 버스 −4dB 0.15초 (화면 멈춤과 같은 순간) | |
| 블레이드 일섬 직전, 섀도우 월영, 퇴마사 멸 직전 | 0.15~0.2초 정적 | 큰 박자를 살림 |
| 보스 페이즈, 그로기 시작, 중형보스 등장 | 효과 −6dB 0.6초 | |
| 보스 처치, 보스층 클리어 | −8dB 1초 | |
| 괴담 깜빡임 | 배경 0 (0.15초) | 숨 멈춤 |
| 내가 탈락 (관전) | 효과 버스 전체 −6dB | |

- 덕킹이 겹치면 **더하지 않고 가장 낮은 값**을 쓰고, 효과 버스는 −14dB 아래로 내려가지 않음.
- 보스 패턴 준비 소리는 궁극기 덕킹을 3dB 덜 받음 (위험 신호가 묻히지 않게).

### 4-5. 좌우 (스테레오)

- 화면 x 위치로 좌우를 정함 (최대 ±0.7). 내 드래그·궁극기·등장은 ×0.4 (가운데에 무게), 보스는 ×0.5, UI·배경은 가운데.
- 화면 밖 소리는 작게 (최소 0.35배), 좌우 ±0.8에 고정.
- 연타는 시전자 둘레 ±0.35 번갈아.
- 오래된 Safari처럼 좌우가 안 되면 모노.
