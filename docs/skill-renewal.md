# 드래그스킬 · 궁극기 리뉴얼 (기획 13차)

> 상태: 설계 완료, 구현 대기 (12차 작업 뒤)
> 요청 원문: "캐릭들의 드래그스킬과 궁극기가 너무 단순한 느낌이 들어. 조금더 화려하고 강력하게 리뉴얼해줘. 그리고 일단 효과음들도 나중에 교체하더라도 다 넣어주고."
> 효과음은 [sfx.md](sfx.md)에 따로 정리함. 이 문서의 숫자는 모두 **추정**이고, 구현한 뒤 벤치(`tests/playtest/drag-bench.ts`)로 다시 재서 맞춤.

## 1. 한 줄 요약

15명의 드래그스킬과 궁극기를 **한 방짜리에서 2~4박자짜리 연속기(준비 → 터짐 → 여운)**로 바꾸고, 위력을 **드래그 약 ×1.6, 궁극기 약 ×1.8**로 올린다. 궁극기에는 **컷인 0.5초**를 넣는다 (게임은 멈추지 않음). 쿨·게이지·드래그 모양의 고정 방향은 그대로다. 너무 쉬워지지 않게 **6층 이후 몬스터 성장만 조금 올려** 1~5층에서는 강해진 느낌이 그대로 나게 한다.

| 무엇이 바뀌나 | 지금 | 리뉴얼 |
|---|---|---|
| 드래그 박자 | 판정 1번, 착지 = 끝 | 2~4단계, 0.3~1.2초 안에 마지막 큰 박자 |
| 드래그 위력 (쿨 1초당 가치) | 로스터 평균 18.0 | **28.5** (×1.58), 15명 모두 94~105% |
| 궁극기 | 누르면 바로 한 번 | 컷인 0.5초 → 연속 공격 → 마무리 일격 (약 ×1.8) |
| 화면 효과 | 착지 멈춤·흔들림만 | 큰 박자에만 멈춤·흔들림, 궁극기에만 화면 전체 번쩍임·어둡게 |
| 보스 | 기절 면역이라 제어가 안 통함 | 모든 스킬에 **그로기 점수** (boss-groggy 게이지용) |
| 소리 | 없음 | 모든 순간에 합성 효과음 (sfx.md) |

## 2. 공통 연출 규칙

### 2-1. 3박자 문법 (모든 드래그·궁극기)

| 박자 | 길이 | 보이는 것 | 규칙 |
|---|---|---|---|
| **준비** | 0.2~0.5초 | 캐릭터 색의 예비 동작: 충전선, 마법진, 낙인 맥박, 조준선 | 다음에 터질 곳을 보여 줌. 내 드래그의 지연 단계는 빨간 채움 대신 **캐릭터 모양의 예고** (아래 2-4) |
| **터짐** | 0.05~0.15초 | 가장 크게 번쩍이는 한 순간 | 멈춤(hit-stop)·흔들림은 **이 박자 한 번에만** |
| **여운** | 0.3~0.8초 (장판은 지속 시간 내내) | 잔상, 불씨, 파편, 장판 테두리 | 화면을 가리지 않게 알파 낮게, 장판은 테두리 장식만 (안을 채우지 않음) |

- 드래그는 **0.6~1.2초 안에** 큰 박자가 끝난다 (예외: 클레릭 종 4초, 워든·가디언 장판 4초 — 장판은 여운으로 침).
- 같은 소리·같은 그림이 여러 번 나오면 (베기 ×4, 순보 ×5) 하나마다 크기나 음높이를 조금씩 올려 **점점 커지게** 한다.

### 2-2. 화면 효과 예산

| | 내 드래그 | 내 궁극기 | 다른 플레이어·봇 |
|---|---|---|---|
| 멈춤 (hit-stop) | 큰 박자 한 번 60~90ms (착지 멈춤은 큰 박자가 따로 있으면 60ms로 줄임). 1초 합 160ms 이하 (`juice.ts` FREEZE_BUDGET) | 마무리 90~110ms (FREEZE_MAX 0.12초 안) | 없음 |
| 흔들림 | 큰 박자 4~7, 나머지 박자 3 이하 | 마무리 8~10, 중간 타격 1.5~2 | 없음 |
| 범위 번쩍임 (모양 안만) | 큰 박자에 0.08~0.15초 | 자유 | k = 0.55로 흐리게 |
| 화면 전체 번쩍임 | **쓰지 않음** | 마무리에 0.08~0.1초, 알파 0.35~0.4 | 알파 절반 |
| 어둡게·채도 빼기·비네트·스포트라이트 | **쓰지 않음** | 컷인과 마무리 직전 | 쓰지 않음 |
| 동시에 살아 있는 입자 | 40개 이하 | 60개 이하 | 지금처럼 OTHER_PLAYER_FX (0.55) |

### 2-3. 궁극기 컷인 (15명 공통)

- **게임(sim)은 멈추지 않는다.** 서버가 판정하는 최대 3인 멀티라서, 한 사람의 컷인 때문에 다른 사람이 멈추면 안 되고, 화면만 멈추면 끝난 뒤 위치가 튄다.
- 대신 데이터로 맞춘다: 궁극기 `castTime 0.5` (제자리 잠금) + **시전자 무적 0.5초** (`ultGuard`) + **모든 효과의 delay ≥ 0.45초**. 그러면 모든 화면에서 컷인이 끝나는 순간 첫 타격이 들어간다. 순간이동·사라지기 같은 움직임만 0초에 해도 됨 (섀도우).
- 순서: 탭 → `ultCast` 이벤트 (컷인 시작) → `skillCast` (예고) → 0.45초부터 효과.
- **내 궁극기** (0~0.5초):
  - 월드만 40% 어둡게 (HUD·시전자·예고선은 밝게), 0.08초에 내려옴.
  - 30° 기운 캐릭터 색 띠 (화면 높이 약 38%)가 0.12초에 밀려 들어옴. 띠 안에 코드로 그린 초상 (`look.ts` 몸을 2.2~3배, 상반신), 스킬 이름 34 논리px 굵게 (폰 약 18px, 흰 글자 + 캐릭터 색 외곽선), 뒤로 흰 속도선.
  - 0.36~0.45초에 띠가 빠지며 흰 와이프 0.06초 → 첫 타격.
  - 캐릭터별 변형 허용: 버서커 붉은 비네트, 섀도우 띠가 베어지듯 갈라짐, 퇴마사 먹 붓질 띠 + 낙관 도장, 퍼펫티어 무대막, 크로노 채도 빼기, 메딕 사이렌 빛.
- **다른 플레이어·봇의 궁극기**: 어둡게 하지 않음. 화면 왼쪽 위에 1/4 크기 미니 배너 (초상 + 이름) 0.6초, 마무리 번쩍임은 절반.
- 설정에 **"컷인 짧게"** (0.25초 배너만) 옵션을 둔다 (반복해서 보면 지겨울 수 있음). 데이터 timing은 그대로.

### 2-4. 예고 (텔레그래프) 규칙

- 몬스터 공격의 빨간 예고는 그대로.
- 내 드래그·궁극기의 지연 단계: 캐릭터 색 **테두리 + 모양 장식**으로 그림 (레인저 조준선 + ››› 화살표, 메이지 룬 마법진, 클레릭 눈금 8개, 거너 단계별로 흐려지는 부채꼴, 크로노 줄어드는 점선 원). 안을 채우지 않음.
- 늦게 터지는 단계는 `telegraphLead`로 마지막 몇 초만 보여 줌 (버서커 8초 뒤 일격, 워든 5초 뒤 해방). `telegraphLead: 0` = 예고 없음 (바로 뒤따르는 단계가 겹쳐 그려지지 않게).
- `follow` 단계는 예고도 대상·시전자를 따라감 (+ 거너·레인저는 조준 십자선).
- 드래그 미리보기 (끄는 동안)는 여러 단계를 **한 외곽선 + 안쪽 표시**로 합쳐 그림 (메이지 7개 원을 따로 그리지 않음).

### 2-5. 폰 가독성 (844×390, 논리 1px ≈ 폰 0.54px)

- 선 굵기 3 논리px 이상 (폰 1.5px), 띠·십자 폭 1.3칸 이상.
- 머리 위 상태 아이콘 12~14px, **적 하나에 2개까지** (도발 「!」, 낙인 십자, 족쇄, X 표식, 「혼」, 「약」, 조종 손잡이, 정지 시계).
- 장판은 테두리만 → 안의 적이 보임.
- 메딕 십자 (아군, 청록·흰 + 전기)와 팔라딘 십자 (적, 하늘색·금 + 빛기둥)는 모양이 같으니 색과 재질로 구분.

## 3. 캐릭터 15명

표 읽는 법: 시간 = 착지(드래그) 또는 탭(궁극기)부터 초. **단계** = 데이터의 `stage` 이름 (연출·소리를 고르는 열쇠). 범위의 "r" = 반경 (칸). 그로기 = 보스·중형보스에게 맞을 때마다 쌓는 점수 (5장 참고). 모든 쿨·게이지(30초)는 그대로.

### 탱커

#### 1. 가디언 — 쿨 10초

- **지금**: 「방패 파동」 가로 띠 7×2 한 번 (175% + 기절 1초) + 자기 보호막 30%. 궁극기 「불굴의 성벽」 반경 4 끌어당김 + 250%, 아군 보호막 — 같은 프레임에 다 터짐.
- **드래그 「성벽 강림」** (좌우 띠 고정, 조준 = 놓은 곳)

| 시간 | 단계 | 범위 | 대상 | 효과 | 그로기 |
|---|---|---|---|---|---|
| 0.00 | slam | 원 r1.8 | 적 | 피해 90% + 기절 0.6초 | 6 |

### 4-3. 보정 계획 — "강해진 느낌은 남기고, 쉬운 판은 막기"

1. **먼저 보정 없이 잰다**: `npx vite-node tests/playtest/balance.ts 40 20` + `tests/review/critic-20f.ts` 240판 (시드 1000/5000/90000). 층별 클리어 시간, 광폭화, 사망을 지금 표 (balance.md 9-5)와 비교.
2. **목표**: 직접 교체 기본 파티 20층 클리어 **50~55%** (지금 46.7% → 조금 쉬워진 정도가 "강해졌다"는 느낌), 1~5층 클리어 시간은 **줄어든 채로 둔다** (가장 먼저 체감하는 곳).
3. **1순위 손잡이: 6층부터의 성장** `floorStatGrowth` 0.70 → 0.74~0.80에서 시작 (8차 기준 0.01당 약 2.5%p). 1~5층에는 안 걸리므로 초반 체감은 그대로.
4. **2순위: 보스 HP** (10·15·20층)를 +10~15%. 보스층 중앙값이 70초 아래로 떨어지거나 광폭화가 10% 아래면.

6. 그로기 (boss-groggy.md)가 들어오면 보스 딜 타이밍이 다시 늘어나므로 **그때 보스 HP를 한 번 더 잼**. 리뉴얼과 그로기를 한 번에 맞추지 말고 순서대로.
7. 같이 볼 것: 원거리만·지원만 파티 (지금 15%)가 리뉴얼로 얼마나 올라오는지, 메아리 인장(echo_seal)이 이제 모든 단계·장판을 다시 시전하므로 유물 가치도 ×1.6이 되는지.

| `SkillAction.stage?: string` | 단계 이름. `skillCast` 이벤트에 `stage`와 `actionIndex`를 실어 보냄 → 연출·소리가 단계마다 고름 (`castfx` 키 = `skillId:stage`) | 탱커 `fx`, 힐러 `stage` → `stage` 하나로 |
| `SkillAction.groggy?: number` | 이 단계가 보스·중형보스를 맞힐 때마다 쌓는 그로기 점수 (일반 몹은 무시) | 탱커는 효과 `{kind:'groggy'}`, 나머지는 액션 필드 → **액션 필드**로 (장판은 틱마다) |
| `SkillAction.follow?: boolean` | 지연된 `self`/`target` 단계를 **터지는 순간의 위치**로 다시 구함. 예고도 따라감. 기본은 지금처럼 시전 순간 위치 고정 | 근접 "중심 다시 구하기" + 원거리 `trackTarget` → 하나로 |
| `SkillAction.telegraphLead?: number` | 지연 단계의 예고를 마지막 N초만 보임. `0` = 예고 없음 | 탱커 `telegraph:false` + 근접 `telegraphLead` → 하나로 |
| 피해 효과 `crit?: 'always'` | 확정 치명타 (치명 판정 건너뜀) | 원거리 `forceCrit` + 섀도우 `crit:'always'` → 피해 효과 필드로 |
| `dash.atFire?: boolean` | 지연 단계가 터지는 순간에 시전자가 밀려남 (거너 반동), 기존 'dash' 이벤트 | 원거리 |
| `charge.stopAtCenter?: boolean` | 돌진이 놓은 곳에서 멈춤 (블레이드 되돌아 베기). 메아리 인장 재시전(`noDash`)은 charge도 건너뜀 | 근접 |
| 궁극기 `castTime 0.5` + `ultGuard 0.5` | 컷인 동안 제자리 + 무적 (기존 `invulnTime` 재사용) | 탱커 0.6 / 근접 0.45 / 나머지 0.5 → **0.5로 통일** |
| 이벤트 `ultCast {player, entityId, skillId, name}` | `useUlt`가 `castSkill`보다 먼저 보냄 → 컷인 시작 | 탱커 |
| 데이터 규칙: 궁극기 효과 delay ≥ 0.45 | 컷인이 끝나는 순간 첫 타격 | 공통 |

### 5-2. 새 상태 (모두 적에게만, `DEBUFFS`에 넣음)

`StatusInstance`에 선택 필드 `data?: { sourceEntityId?, anchor?, radius?, stored? }`를 하나 추가해 아래 상태들이 같이 쓴다.

| 상태 | 하는 일 | 보스·중형보스 | 쓰는 곳 |
|---|---|---|---|
| `taunt` (도발) | 대상을 건 캐릭터로 고정 (`units.ts` 대상 고르기에서 1순위). 건 캐릭터가 죽거나 나가면 풀림 | 면역 (정지 유닛도) | 가디언 |
| `tether` (묶기) | 기준점에서 반경 R 밖으로 못 움직임 (이동 뒤·밀기 뒤에 잘라냄). 장판이 0.6초짜리로 계속 다시 걸어 장판과 함께 풀림 | 면역 | 워든 |
| `root` (속박) | 움직이지 못함, 공격은 함. **tether 반경 0으로 구현** (자기 자리 기준) | 원래 안 움직임 | 퇴마사 |
| `stasis` (정지) | 이동·공격·공격 준비·스킬 쿨·예고 공격 타이머가 모두 멈춤 (예고 공격은 취소 아니고 미뤄짐). 받은 피해를 모아 끝날 때 value × 누적을 다시 줌 (보스 최대 HP 6% 상한), 이벤트 `stasisEnd {entityId, amount}` | **걸림**, 지속 ×0.6. 끝나고 10초간 다시 안 걸림 (추천) | 크로노 |
| `charm` (조종) | 가장 가까운 다른 적을 노리고, 그 피해가 적 팀에게 들어감 (기여 = 건 플레이어) | 면역 (소환물도) | 퍼펫티어 |
| `splashUp` (버프, 아군) | 기본 공격 스플래시 반경 +value (없던 캐릭터는 새로 생김) | – | 버서커 |

taunt와 charm은 같은 "대상 덮어쓰기" 자리 (`pickTarget`)를 쓰고, tether와 root는 같은 "위치 잘라내기" 자리를 쓴다.

### 5-3. 캐릭터 몇 명만 쓰는 것

| 규칙 | 하는 일 | 쓰는 곳 |
|---|---|---|
| `SkillAction.blinkChain {count, radius, interval, maxPerTarget}` | 반경 안 적에게 차례로 순간이동하며 그 자리에서 판정 (안 맞은 적 먼저), 순보마다 'blink' 이벤트 | 블레이드 궁극기 |
| `SkillAction.maxTargets?: number` | 범위 안에서 가까운 순 N명만 (거리 → id 순, 결정적) | 퍼펫티어 궁극기 |
| `SkillAction.healPerHit {radius, amount, maxHits}` | 이 단계에 맞은 적 수만큼 놓은 곳 반경 안 아군 회복 (한 번에), heal 이벤트 `from` = 첫 적 | 퇴마사 |
| 회복 효과 `overflowShield {frac, cap, duration}` | 넘친 회복을 보호막으로 (`addShield` 재사용) | 클레릭 |
| 드래그에서 `center:'woundedAlly'` + `allyRange` | **놓은 곳** 기준 반경 안 HP 비율이 가장 낮은 아군 (모든 플레이어 + 환자, 동점이면 가까운 쪽) | 메딕 |
| 효과 `benchStatus {status, duration, value, allPlayers?}` + 이벤트 `benchBuff` | 대기 멤버에게 상태를 넣음 (대기 타이머는 이미 흐르고 등장할 때 그대로 가져감) | 바드 |
| `swapCooldownReduce.allPlayers` | 모든 플레이어 대기 쿨 감소 | 크로노 궁극기 |
| 이벤트 `reviveCut {player, partyIndex, seconds}` | 부활 숫자가 굴러 떨어지는 연출용 | 메딕 궁극기 |
| 소환물 `paper_doll_grand` (데이터만) + `paper_doll.onDeath` 숫자 변경 | 대형 인형 | 퍼펫티어 |

### 5-4. 렌더만 (sim 변경 없음)

2-7의 부품 전부, 끌어당김 보간 (PullLerp), 컷인 동안 섀도우 숨기기, 정지된 적 회색 + 애니메이션 멈춤, 드래그 미리보기 합치기 (`previewParts`), 봇 조준 (`partsForActions`)이 여러 단계를 이해하도록.

### 5-5. 이미 되는 것 (확인함)

지연·오프셋·여러 번 맞히기·직사각형/원 장판·한 자리에 아군 장판과 적 장판·장판 안에서 0.6초짜리 상태 다시 걸기 (강한 값·긴 시간이 남음)·대기 회복·부활 감소·흡혼·끌어당김·넉백·소환. 교체돼 나가도 이미 시작된 지연 단계와 장판은 끝까지 감 (지금 메이지 유성과 같은 규칙).
