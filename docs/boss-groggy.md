# 보스 그로기 — 통합 기획서 (기획 13차)

> **상태: 구현됨 (기획 13차, 추천 기본값 전부).** 구현 메모: ① 보스 HP는 구현 때 바꾸지 않았고, **차수 끝 밸런스 단계에서 8장 +12% 묶음을 10층에만** 넣음 (야근의 군주 8000 → 9000; 5층은 '1~5층 그대로' 원칙, 15·20층은 6층 이후 성장 0.7 → 1.33만으로 싸움 길이가 12차 수준 — 8장 끝 '13차 밸런스 결과', balance.md 12장) ② '쓰러뜨린 횟수'는 쓰러지는 순간 +1(같은 뜻: 그로기·잠금 중에는 게이지가 안 차므로 최대치 계산은 같음) ③ 피해 이벤트에 `groggy` 외에 `drag`도 달아 '×2'를 정확히 표시(종이 인형 터짐은 드래그 출처지만 ×1.5) ④ 디버그 `forceGroggy`에 `fill`(0~1, 예: 0.85 = 거의 참) ⑤ 폰에서는 박스 여백·상태 칸 높이를 줄여 박스 아래 끝을 그대로(y≈96) 유지. 구현 위치는 prototype-architecture.md 13차 장.
>
> **통합 확인 (13차 통합, 2026-10-06)**: 멀티 3화면에서 게이지 값·`groggyGain`·쓰러짐(`bossGroggy`)·카운트다운·일어남·잠금이 같음(e2e 「보스 그로기·궁극기 컷인 (13차)」, `multi-groggy-b.png`). 통합 때 바꾼 것: 쓰러지는 순간 끊긴 준비 동작이 여럿이면 '끊김!'을 한 자리에 하나만(겹쳐 찍히던 것). 남은 차이: 그로기 빈도는 밸런스 단계 숫자 그대로(보스전마다 약 2번, 첫 그로기 18~20초 — 목표 20~35초의 앞쪽 끝), 화면 문구 '×1.5 · ×2'는 고정 글자.
>
> 요청 원문: "보스 그로기를 넣어줘." (제안: "보스에게 그로기 게이지가 있어서, 기절·드래그 스킬로 채우면 보스가 5초간 쓰러지고 받는 피해 1.5배. '지금이다!' 하고 교체를 몰아 쓰는 폭딜 타이밍이 생겨요.")
>
> 두 관점으로 따로 설계한 뒤 합쳤다. **손맛·연출 쪽(1안)**에서는 쓰러지는 순간의 연출, 보스별 자세, '지금!' 카드 신호, 그로기 중 보스 쿨 멈춤을 가져왔다. **시스템·수치 쪽(2안)**에서는 게이지 공식, 채우는 양, 감소, 잠금, 반복 증가, 봇 규칙, 보스 HP 보정과 측정값을 가져왔다. 숫자는 2안이 실제 시뮬로 잰 값이다(잰 방법과 주의점은 8장).
>
> 표시: **[새 코드]**는 지금 게임에 없는 계산을 새로 만들어야 하는 부분이다. **[재사용]**은 지금 있는 기능(기절, 준비 동작 끊기, 페이즈, 배너)을 다시 쓰는 부분이다.

## 1) 한 줄 요약
보스 바 바로 밑에 **그로기 게이지**가 생긴다. 주로 **드래그 스킬과 기절**로 채운다. 가득 차면 보스가 **5초간 쓰러져** 아무것도 못 하고, 그동안 **받는 피해 ×1.5, 드래그 스킬은 ×2**가 된다. 기절 카드로 쓰러뜨리고 딜 카드를 몰아 넣는 **"지금이다!" 교체 타이밍**이 보스전마다 1~2번 생긴다.

---

## 2) 게이지

### 기본 구조
- **보스 하나에 게이지 하나**, 팀 전체가 같이 채운다(사람·봇 모두).
- 게이지는 시뮬 안에서 **0~1 비율**로 저장한다. 채울 때는 `점수 ÷ 지금의 최대치`만큼 오른다. 그래서 중간에 누가 나가서 봇이 되거나 다시 들어와도 **막대가 튀지 않고 차는 속도만 바뀐다**. **[새 코드]**
- 난수를 쓰지 않는다. 같은 시드면 같은 순간에 쓰러진다.

### 언제 채워지나
아래를 모두 만족할 때만 오른다.
- 보스층 전투 중이고, 보스가 살아 있다.
- 보스가 등장 무적 상태가 아니다(`invulnTime = 0`).
- 지금 **그로기 중이 아니고, 잠금(10초) 중도 아니다**.
- 행동이 **보스에 실제로 닿았다**(스킬이 맞는 순간 `skills.ts applyEffects`에서 판정). 보스는 반지름 3이라서 보스층 드래그의 98~100%가 이미 보스에 닿는다.

### 무엇이 얼마나 채우나 (점수)

| 행동 | 점수 | 메모 |
|---|---|---|
| **드래그 스킬이 보스에 닿음** | **10** | 드래그 한 번에 **딱 1번**. 메이지 유성우 5발 = 10 (50 아님), 섀도우 3연격 = 10 |
| 드래그 스킬의 **기절**이 보스에 닿음 | **기절 1초당 15** | 위 10에 더한다 |
| 궁극기의 기절 | 기절 1초당 10 | |
| 펫의 기절 | 기절 1초당 5 | |
| 일반 스킬의 기절 | 기절 1초당 2 | 가디언 방패 강타 = 7초마다 2 |
| 기본 공격, 그냥 피해, 둔화·넉백·끌기, 지속 피해, 장판 | **0** | 딜 경쟁이 아니라 **교체·제어 게이지**다 |
| 메아리 인장(echo_seal)으로 다시 나간 드래그 | 0 | 한 번 교체 = 한 번 점수 |
| 아군만 고치는 드래그 (클레릭 치유의 샘, 메딕 응급 처치) | 0 | 힐러의 값은 회복이다(10장 8번) |

- 보스는 **지금처럼 기절에 걸리지 않는다**(`status.ts` 그대로). 보스에게 간 기절은 **걸리는 대신 게이지 점수로 바뀐다**. 그래서 아무도 기절로 그로기를 늘릴 수 없다.

**캐릭터별 드래그 한 번 (보스에 닿을 때)**

| 드래그 | 점수 | 처음 최대치(100) 대비 |
|---|---|---|
| 가디언 방패 파동 · 팔라딘 심판의 십자 · 크로노 시간 균열 (기절 1초) | **25** | 약 1/4 |
| 블레이드 질풍 돌파 (기절 0.4초) | 16 | |
| 섀도우 그림자 연격 (기절 0.3초) | 14.5 | |
| 레인저 · 메이지 · 거너 · 버서커 · 바드 · 워든 · 퇴마사 · 퍼펫티어 | 10 | 적을 때리는 드래그면 모두 |
| 클레릭 · 메딕 | 0 | |

**궁극기·펫 예시**: 크로노 시간 정지(2초) 20, 워든 철옹성(1.2초) 12, 팔라딘 천상의 심판(1초) 10, 서리 부엉이 5, 블랙홀 고양이 2.5.

> 12차 새 캐릭터(메딕·퇴마사·퍼펫티어)는 드래그 데이터에 '적에게 맞음 / 기절' 부분이 있느냐로 자동으로 정해진다. 12차 숫자가 바뀌어도 이 규칙은 그대로다.

### 최대치

```
최대치 = 100 × 보스 배수 × 인원 배수 × 반복 배수
```

| | 값 |
|---|---|
| **보스 배수** (`BossDef.groggy.threshold`) | 5층 엘리베이터 **0.8** (첫 보스, 처음 배우는 자리) · 10층 야근의 군주 1.0 · 15층 수술실 원장 1.0 · 20층 심연의 감시자 **1.1** |
| **인원 배수** | 1 + 0.4 × (사람 수 − 1) → 1명 **×1.0** · 2명 **×1.4** · 3명 **×1.8**. 봇이 아닌 자리 수를 **실시간으로** 센다(게이지가 비율이라 막대는 튀지 않음) |
| **반복 배수** | 1 + 0.5 × 지금까지 쓰러뜨린 횟수 → 100 → 150 → 200 → 250 |

예: 사람 1명이면 5층은 80 → 120 → 160, 20층은 110 → 165 → 220. 사람 3명이면 10층 첫 그로기가 180이다.

### 감소
- **4초 동안 아무 점수도 못 얻으면** 초당 **4점**씩 줄어든다(0 밑으로는 안 감).
- 그로기 중과 잠금 중에는 줄지 않는다.
- 보통 교체 리듬(4.5~6초마다 한 번)으로 치면 거의 안 줄어든다. 손을 놓고 있거나 봇만 있을 때 줄어든다. '몰아 쓰기'가 의미 있어지는 장치다.

### 반복 그로기 — 영구 기절을 막는 장치
- 그로기 5초가 끝나면 게이지는 0에서 **10초 잠금**(회색 빗금이 다시 차오름, 이 동안 점수 안 받음).
- 다음 최대치는 50% 늘어난다.
- 그래서 그로기와 그로기 사이는 **최소 15초 + 늘어난 게이지를 채우는 시간**이다.
- 측정한 최악의 경우(사람 3명이 모두 가디언·팔라딘·크로노): 140~160초 싸움에서 4~4.7번, **보스가 누워 있는 시간 약 15%**.

### 예상 속도 (실제 시뮬, 보스층)

| 파티 | 첫 그로기 | 두 번째 | 한 싸움에 |
|---|---|---|---|
| 사람 1명 + 봇 2 (직접 교체) | 29~33초 (5층 29초) | 74~84초 | **1.4~1.55번** |
| 사람 3명 | 23~29초 | — | 1.1~1.5번 (싸움이 10~14초 짧아서) |
| 봇만 3명 | 42~54초 | — | 약 1.2번 |

- 사람 1명 판에서 게이지의 약 55%는 봇 두 자리(가디언 기절, 기절 펫)에서 나온다.

## 3) 그로기 중

### 시간
- **모든 보스 5.0초**. 반복해도 줄지 않는다(대신 최대치가 커진다). 그래서 창의 길이는 언제나 똑같이 읽힌다.
- **도중에 끝나지 않는다.** 끝나는 경우는 보스 HP 0(후퇴), 층 클리어, 런 종료뿐이다.

### 쓰러지는 순간 (같은 틱)
1. 게이지를 마지막으로 채운 플레이어가 **'쓰러뜨린 사람'**이 된다(표시용, 보상 없음).
2. 보스에게 **그로기용 기절 상태**(출처 'groggy')를 건다. 새 함수 `applyGroggy()`가 보스 기절 면역을 이 경우에만 건너뛴다. 지금 기절 규칙을 그대로 쓴다: 행동 멈춤, 공격 타이머 멈춤, 보스 아이콘 줄에 기절 아이콘. **[재사용 + 새 코드, 작음]**
3. **아직 시작하지 않은 준비 동작을 모두 끊는다**. 지금 기절이 쓰는 길 그대로라서, 바닥의 빨간 예고가 전부 '끊김!'과 함께 사라진다. 여러 갈래 패턴(문이 닫힙니다의 띠 4개, 도장 연타)도 전부 끊긴다. 이미 떨어진 공격, 이미 시작한 연타, 이미 깔린 장판(마취 가스)은 남는다. **[재사용]** (`status.ts`의 끊기 부분을 `breakWindup(e)`로 빼서 같이 쓴다.)
4. 이미 쓴 스킬 쿨은 돌려주지 않는다.

### 그로기 동안 보스
- **기본 공격도 스킬도 안 쓴다.**
- **스킬 쿨이 멈춘다** (보스만). 일반 몬스터는 4차 규칙대로 기절 중에도 쿨이 흐르지만, 보스까지 그러면 일어나자마자 패턴 2~3개가 한꺼번에 쏟아진다(8차 리뷰가 잰 '패턴 2개 이상 동시 예고' 문제). **[새 코드, 작음]**
- 일어난 뒤 첫 패턴은 **최소 1.5초 뒤**에 온다(`skillGap ≥ 1.5`).

### 받는 피해

| 출처 | 배율 |
|---|---|
| **드래그 스킬** (교체로 나간 스킬) | **×2.0** |
| 그 밖의 모든 아군 피해 (기본 공격, 일반 스킬, 궁극기, 펫, 포탑, 장판, 유물) | ×1.5 |
| 보스가 아닌 적 (소환수 등) | 배율 없음 |

- `combat.ts applyDamage`에서 '취약' 다음, 방어력 앞에 곱한다. 취약·분노 파괴 같은 다른 배율과는 곱으로 쌓인다.
- 피해 이벤트에 `groggy: true`를 단다(숫자 색을 바꾸려고).

### 페이즈
- HP 기준(50/60/30/25%)은 그로기 중에도 **바로 넘어간다**. 보스 바의 ◆ 페이즈 표시도 바로 바뀐다. 그래서 어떤 페이즈도 건너뛰지 않는다.
- 새 페이즈 스킬도 쿨이 멈춘 채로 들어가므로, **첫 패턴(opener)은 일어난 뒤에** initialDelay(1.5초)가 지나야 나온다.
- **페이즈 배너는 일어날 때 띄운다**(일어나고 0.4초 뒤). '2페이즈'라는 글자가 새 패턴이 진짜 오는 때와 맞고, 그로기 연출과 겹치지 않는다. "화나서 일어난다"는 장면이 된다.
- 페이즈가 바뀌어도 그로기는 끝나지 않고 게이지도 초기화되지 않는다.

### 광폭화
- **광폭화 타이머는 그로기 중에도 흐른다.** 그로기는 역전 수단이지 시간 연장이 아니다.
- 그로기 중에 광폭화가 오면 바로 적용된다(공격력, 멈춘 쿨 ×0.6, 배너). 보스는 5초를 다 누워 있다가 **광폭화한 채로 일어난다**.
- 광폭화 뒤에도 그로기 규칙(최대치, 배율)은 같다.

### 소환수·쫄
- 이미 나와 있는 소환수(엘리베이터의 그림자 아이 등)는 **계속 싸운다**. 보스 스킬이 멈췄으니 새로 나오지는 않는다. 그로기는 공짜 시간이 아니고, 쫄은 여전히 처리해야 한다.
- 쓰러질 때 충격파 링은 **연출만** 있다. 쫄을 기절시키는 효과는 v1에 넣지 않는다(10장 4번).

### HP 0
- 그로기 중 HP가 0이 되면 지금처럼 **후퇴 → 층 클리어**. 그로기 상태는 `bossRetreat`와 `floorClear`에서 지운다.

### 일어날 때
- 그로기 끝 → 게이지 0, 10초 잠금 시작, 횟수 +1, 보스 첫 패턴은 최소 1.5초 뒤, 'bossGroggyEnd' 이벤트.

## 4) 범위

**v1은 층 보스 4명만** (5·10·15·20층). 중간 보스(거대 마네킹, 검은 조문객, 엘리베이터 걸, 복사기 괴물, 수간호사, 신호등 인간)는 4차 규칙 그대로 둔다.

이유:
1. 중간 보스는 **이미 기절이 걸리고, 기절이 준비 동작을 끊는다**(4차). 이미 작은 '끊기'가 있다. 게이지를 더 얹으면 4차 리뷰가 확인한 기절 연속 문제가 다시 생긴다.
2. 중간 보스는 웨이브 사이 45~75초짜리 곁가지다. 5초 창을 넣어도 판단은 별로 안 늘고 소리만 커진다.
3. 일반층에는 이미 금색 **돌발 괴담** 배너·알약과 '약점' 표시(12차)가 있다. 금색 장치가 둘이면 둘 다 흐려진다. 돌발 괴담은 보스층에서 안 나오므로 보스층에서는 겹치지 않는다.
4. 중간 보스 HP 바는 작아서 게이지 줄을 넣을 자리가 없다.
5. 그로기는 **보스전에서만 일어나는 사건**이어야 특별하다. 지금 보스전에는 제어 수단이 아예 없다(보스는 기절·넉백 면역). 이 기능이 메우는 빈칸이 바로 거기다.

나중에 원하면: 데이터 `groggy` 칸을 중간 보스에도 줄 수 있게 만들어 둔다. 후보는 '비틀' 판(게이지 50, 2.5초, ×1.3, HP 바 둘레 고리로만 표시)이다(10장 10번).

## 5) 교체·드래그와의 연결

### 1. 채우는 것도 드래그, 끝내는 것도 드래그
- 기절 드래그 하나 = 25점 = 막대의 약 1/4. 그 밖의 드래그 = 10점. 기본 공격은 0점.
- **그로기 중에는 게이지가 안 찬다.** 그래서 쓰러진 보스에 기절 카드를 넣으면 낭비다.
- 그로기 중 드래그는 **×2**, 나머지는 ×1.5. 메이지 유성우는 5발이 다 반지름 3의 보스에 떨어져서 가장 크게 이득이다. 레인저 310%, 거너 300%, 블레이드 270%도 좋다.
- 자연스러운 손놀림: **탱커·서포터 카드로 쓰러뜨리고 → 딜러 카드로 마무리.** 지금 있는 '쿨 판단'에 **'카드 순서' 판단**이 하나 더 생긴다.

### 2. 쓰러뜨리는 때를 고른다
- 80%를 넘으면 '다음 기절 드래그면 쓰러진다'는 신호가 나온다(6장).
- 딜 카드 쿨이 거의 끝날 때까지 기다렸다가 쓰러뜨릴 수 있다 — **"지금이다!"**
- 대가: 4초가 지나면 초당 4점씩 줄어든다. 카드 3장 교체 주기(4.5~6초마다 한 번)가 이 안에 들어간다.
- 그로기 동안 **준비된 카드에 금색 테두리 + '지금!'**이 붙어서, 마무리 교체가 눈에 바로 들어온다.

### 3. 다른 플레이도 쓸모 있다
- 모든 피해가 ×1.5, 궁극기·펫·일반 기절도 게이지를 채운다.
- 보스가 5초 동안 아무것도 안 해서 **파티 전체가 산다**: 보스전 사망이 15~25% 준다(예: 20층 5.62 → 4.76명).
- 필드에 없는 카드도 손해 없음. 궁극기를 아껴 뒀다가 그로기 때 쓰는 것은 선택 사항이다(궁극기도 ×1.5).

### 4. 일부러 넣지 않은 것
- **쓰러질 때 교체 쿨 줄여 주기**: 넣지 않는다. 크로노·토끼가 이미 그 역할을 하고, 그로기가 '아무 카드나 다 쏟는 창'이 되면 순서 판단이 사라진다. 측정에서 '그로기 창 안 드래그 비중'이 낮게 나오면 다시 본다(10장 3번).
- 드래그 ×2를 ×1.5 대신 쓴 비용은 20층 클리어 +0.4%p(오차 안)였다. **교체 보너스는 밸런스상 거의 공짜**다.

### 툴팁 한 줄
**"드래그·기절로 채우고, 그로기 땐 딜 드래그로 끝낸다."**

## 6) 화면 (폰 844×390 가로, 논리 해상도 1280×720, 약 0.54배)

크기는 논리 px다. [ ] 안은 작은 화면(`.stage.is-small`) 값.

### 보스 박스 (위 가운데, 폭 420)
- HP 바 **바로 밑에 그로기 줄**: 폭 396(HP 바와 같음), 높이 9 [11], 간격 3, 모서리 4.
  - 빈 칸 #2a1f05, 채움 호박색 그라데이션 #ffd166 → #f4a300, 25/50/75% 눈금.
  - 왼쪽 여백에 14 [17] px 별(기절) 아이콘. 평소엔 글자 없음(0.54배에서 8~9px 글자는 안 읽힌다).
- 자리 만들기: 아이콘 줄 위 여백 5 → 3. 박스가 약 7px 커지고 아래 끝이 y≈90. 보스 그림 한계(8차, `BOSS_DROP` 기준 y≈95) 안이다. **보스 4명 스크린샷으로 눈이 박스에 안 가리는지 꼭 확인.**
- 건드리지 않는 것: `.boss-row`(Lv, 이름, 광폭화 알약, ◆◇ 페이즈 표시, %), HP 바의 페이즈 눈금(그로기 줄에는 눈금을 안 그림).

### 채울 때
- 점수를 얻으면 줄이 0.15초 하얗게 번쩍.
- **5점 이상**이면 채움 끝에서 '+N'이 12px 떠오른다(14 [17]px, 그 플레이어 색, 0.6초). 멀티에서는 누가 채웠는지 색으로 보인다.

### 거의 참 (80% 이상)
- 줄이 깜빡인다(투명도 0.7↔1, 0.45초, CSS만, `.boss-enrage`와 같은 방식). 오른쪽 끝에 **⚡** (16 [19]px). 박스 테두리가 금색.
- **보스 그림이 떨린다**(좌우 ±2px, 90% 이상 ±3px). 머리 위에 작은 별 2개가 돈다. 90% 이상이면 그림에 금색 금 1~2줄.

### 쓰러지는 순간
- **멈칫 180ms**(드래그 착지는 75ms), **화면 흔들림은 드래그 착지의 2배**. `juice.ts`의 '움직임 줄이기' 설정은 그대로 따른다.
- 보스에 하얀 번쩍(페이즈 번쩍 재사용, 세기 1), 보스 발밑에서 **금색 충격파 링**(0.45초에 반지름 9까지), 금색 조각 12개, 빨간 예고가 전부 '끊김!'으로 터진다.
- **도장 「그로기!」**: 보스 그림 위(드롭 필드가 아니라) 월드 좌표에 찍는다.
  - 64 [76]px 금색 #ffd166, 4px 어두운 테두리. 0.18초에 1.6 → 1.0배로 줄어들고, 0.6초 머문 뒤 0.3초에 사라진다.
  - 아랫줄 22 [26]px 흰색: **'받는 피해 ×1.5 · 드래그 ×2'**.
  - 멀티에서 셋째 줄 18px(쓰러뜨린 사람 색): **'○○가 쓰러뜨림'**. 내가 쓰러뜨렸으면 **'내가 쓰러뜨렸다!'**.
  - 아래쪽 `.banner` 띠는 쓰지 않는다. 그 띠는 페이즈·광폭화 배너 자리이고, 미뤄 둔 페이즈 배너가 일어날 때 나오기 때문이다.

### 그로기 중 — 카운트다운
- 그로기 줄이 밝은 금색이 되고 **오른쪽에서 왼쪽으로 5초 동안 줄어든다**. 이것이 카운트다운이다.
- 보스 박스 아래쪽 **시전 알약 자리**(`.boss-cast`)가 그로기 알약이 된다: 금색 테두리, 진한 호박 배경, **'그로기! 4.2초 · 드래그 ×2'** (17 [21]px, 숫자 폭 고정). 쓰러진 보스는 시전을 안 하므로 자리가 겹치지 않는다.
- 박스에 호박색 빛(`.boss.is-groggy`). 광폭화 중이면 빨간 광폭화 테두리가 이기고, 호박색 알약·카운트다운은 그대로.
- **마지막 1.5초**: 줄과 알약이 빨갛게 깜빡 ('곧 일어나요').
- **카드**: 준비된 대기 카드마다 2px 금색 테두리가 뛰고 **'지금!'** 표시(16 [19]px).
- **피해 숫자**: 호박색 #ffc94d, 1.15배 크기, 치명타 모양은 그대로. **드래그 피해는 오른쪽에 작은 흰색 '×2'**. 돌발 괴담의 금색 '약점' 글자는 쓰지 않는다(그건 돌발 괴담 전용 말).

### 잠금 (10초)
- 그로기 줄에 회색 빗금이 0 → 100%로 다시 찬다. 글자 없음. '지금은 못 채운다'가 바로 보인다.
- 보스가 다시 시전하면 시전 알약이 지금처럼 자리를 되찾는다.

### 일어날 때
- 0.8초 일어나는 자세(그림만). **0.4초 뒤** 미뤄 둔 페이즈 배너(있으면).

### 보스 자세 (5초 동안 가만히 있으니 자세가 장면을 판다)
모든 보스 공통 바탕: 그림이 14px 내려앉고 6° 기울어짐, 색 35% 바램, 머리 위 큰 기절 별(지금 `drawStunStars` 2배). 0.25초에 들어가고 0.8초에 일어난다. **페이즈 색조와 광폭화 기운은 그대로 둔다**(페이즈·광폭화가 계속 보이게).

| 보스 | 쓰러진 자세 | 일어날 때 |
|---|---|---|
| 5층 닫히지 않는 엘리베이터 | 문이 드디어 **쾅 닫힌다**(질 때만 닫히는 농담). 문틈을 잡던 손이 축 늘어지고, 틈 사이 빛과 큰 눈이 꺼지고, 노란 **'점검중'** 팻말이 떨어져 문 앞에서 흔들린다 | 문이 삐걱 열리며 빛이 다시 쏟아진다 |
| 10층 야근의 군주 | **책상에 엎드려 잠든다.** 팔이 떨어지고 도장·서류가 흩날리고, 눈은 감은 선, 'Zzz' 거품 | 자명종에 놀라 팔을 허우적 |
| 15층 수술실 원장 | 수술등이 **지직거리다 꺼지고**, 메스가 떨어져 바닥에 꽂히고, 머리 위 심전도가 **'삐—' 일직선**, 몸이 처진다 | 심전도가 튀고 등이 탁 켜진다(2페이즈 이상이면 빨강) |
| 20층 심연의 감시자 | 큰 눈이 **질끈 감겼다가** 가끔 빙글빙글 눈동자로 살짝 뜬다. 촉수가 바닥까지 축 늘어지고 작은 눈들도 감기고 균열 후광이 30%로 어두워진다 | 눈이 **핏빛으로 번쩍** 뜬다 |

> 구현은 공통 바탕을 먼저 넣고(그것만으로 v1 동작 확인 가능), 보스별 자세는 그다음에 얹는다(9장).

### 처음 한 번 안내
- 5층에서 기기당 한 번(`tipSeen 'hint:groggy'`): **'ⓘ 드래그·기절로 그로기 게이지를 채우면 보스가 5초간 쓰러져요'**.

### 소리·진동
- 모든 신호는 눈으로 본다. 소리 없음. 진동은 v1에서 끈다(10장 12번).

## 7) 봇 · 멀티

### 봇 (`src/sim/bot.ts` `think()`, 숫자는 `constants.ts`의 `BOT`)
봇도 사람과 **같은 게이지 규칙**을 따른다(자리별 가중치 없음).
1. **쓰러뜨렸을 때 반응**: 준비된 카드가 있는 봇은 다음 정기 교체를 당긴다. `nextSwapAt = min(nextSwapAt, 지금 + 0.5~1.5초)` (지금 `BOT.reaction`과 같은 반응 시간, 시드 난수). 준비된 카드 중 **기절 없는 드래그 + 피해 합이 가장 큰 카드**(마무리)를 고르고, 없으면 지금처럼 고른다.
2. **거의 참(80% 이상, 잠금 아님)**: 정기 교체 때 **기절 드래그 카드를 먼저** 고른다(쓰러뜨리는 역). 교체 시각은 당기지 않는다. 봇이 게이지 경주에서 사람 몫을 뺏지 않게 하려는 것이다.
3. **궁극기**: 그로기 중에 궁극기가 가득이면 0.5초 안에 쓴다(`ultAt = min(ultAt, 지금 + 0.5)`). 그로기를 위해 아껴 두지는 않는다.
4. **긴급 교체(HP 30% 미만)와 돌발 괴담 규칙이 먼저**다. 보스 노리는 가중치는 그대로(드래그가 이미 98~100% 보스에 닿음).
- 새 명령 없음. 사람과 같은 Command 길. 접속이 끊긴 자리도 같은 코드.
- 난수는 쓰러질 때 봇마다 한 번만 뽑는다 → 결정적. 봇 기준 실행(BOT_PRESETS)은 5층 첫 그로기부터 달라지므로 기준선을 다시 잡는다.

### 멀티 (서버가 판정, 클라는 그리기만)
- **상태** (`GameState.bossGroggy`, 일반층은 `null`):
  `{ fill: 0~1, left: 남은 초(0이면 그로기 아님), total: 5, lock: 남은 잠금 초, lockTotal: 10, count: 쓰러뜨린 횟수, near: 80% 이상, breaker: 마지막으로 쓰러뜨린 플레이어 | null }`
  - 소수 둘째 자리로 줄여 스냅샷당 약 70바이트. 재접속·중간 참여 때도 상태만 보고 그린다(HUD가 이벤트로 추측하지 않음).
- **이벤트**:
  - `bossGroggy` { entityId, player(쓰러뜨린 사람 또는 null), count, duration }
  - `bossGroggyEnd` { entityId }
  - `groggyGain` { player, amount, why: 'drag' | 'stun' | 'ult' | 'pet' } — **5점 이상만**('+N' 표시용, 초당 몇 개 안 됨)
  - `damage` 이벤트에 `groggy?: true`
- **사람 수 배수**(1 / 1.4 / 1.8)는 실시간 사람 자리로 센다. 게이지가 비율이라 접속 끊김(자리 → 봇)이나 재접속 때 막대가 아니라 **차는 속도**만 바뀐다.
  - 측정: 사람 3명은 1명 + 봇 2보다 약 2배 빨리 채운다(분당 450~470 vs 230~300점). 배수 1.8이 있어도 첫 그로기 23~29초, 한 싸움 1.1~1.5번.
  - 사람 3명 클리어 +1.3%p뿐(88.3 → 89.6%). 지금 있는 '사람 3명 = 쉬움' 차이를 **더 벌리지 않는다**.
- **공로 기록** (`ContributionStats`): `groggyPoints`(채운 점수), `groggyBreaks`(쓰러뜨린 횟수), `groggyDamage`(그로기 중 넣은 피해). 결과 화면 '보스 피해' 옆에 '그로기 기여'. **보상은 없다**(보상이 있으면 세 사람이 협력 대신 막타 경쟁을 한다).
- **지연**: 5초 창과 카운트다운이 100~250ms 왕복 지연을 덮는다. 마지막 0.2초에 놓은 드래그가 일어난 뒤에 떨어질 수 있는데, 서버 기준으로 맞는 결과이고 카운트다운이 보여 준다.
- **방장 조절값**(디버그 패널 + 멀티 방장, 다른 Tunables처럼 검사): `bossGroggyThreshold` 100 (0 = 기능 끔) · `bossGroggyDuration` 5 · `bossGroggyDamageMult` 1.5 · `bossGroggyDragMult` 2.
- **디버그**: `{ kind: 'forceGroggy' }`(게이지를 꽉 채움), 방장만. e2e 스크린샷에 쓴다.
- 서버 명령 검사는 바뀌지 않는다(새 명령 없음). 조절값 검사만 추가.

## 8) 밸런스

### 잰 방법 (주의)
- 시뮬을 밖에서 돌리는 임시 프로브로 쟀다. 기절 상태 넣기, 보스 쿨 멈추기, 준비 동작 끊기, 피해 배율을 실제 규칙대로 흉내 냈다.
- 정책 = critic-20f 'active'를 옮긴 것(블레이드·메이지·클레릭 + 봇 2), 괴담 방·돌발 괴담 끔, 시드 1000/5000/90000 × 80 = **240판**(20층 전체).
- **주의**: 이 체크아웃은 12차 작업 중이고 옮긴 정책도 critic-20f와 조금 달라서, 기준 클리어가 문서의 46.7%가 아니라 **65.8%**로 나왔다. **절대값이 아니라 차이(±4%p 오차)를 믿는다.** 12차가 끝나면 진짜 critic-20f로 다시 잰다.

### 보정 없이 넣으면 (제안 그대로: 5초, ×1.5)
- 클리어 65.8% → **80.0% (+14%p)**. 보스전이 7~12초 짧아지고 광폭화가 거의 사라진다(0~5%).
- HP ×1.12로도 77.9%, ×1.2로도 71.7%(+6%p). 이득의 대부분은 **피해가 아니라 안전**(보스가 5초씩 2번 쉬고, 준비 동작이 끊김)이라서 HP만으로는 다 지울 수 없다.

## 10) 기획 확인이 필요한 것 (추천 기본값)

1. **그로기 세기**: 5초, 받는 피해 ×1.5, 드래그만 ×2 → **추천: 그대로.** 드래그 ×2의 비용은 클리어 +0.4%p로 오차 안이고, 교체 타이밍의 핵심 보상이다. (펫도 ×2로 할지는 → 추천: 아니오, 펫은 ×1.5. '드래그 = 교체 보상'을 선명하게.)
2. **보정과 클리어율**: 보스 HP +12%(9500 / 9000 / 8300 / 8100)로 싸움 길이는 지금과 같게. 그래도 사람 1명 클리어는 +6~8%p 오른다(보스가 쉬는 동안 덜 죽어서) → **추천: 새 손놀림의 보상으로 받아들인다.** 더 줄이고 싶으면 HP +3%씩, 그다음 반복 증가 0.75.
3. **쓰러질 때 교체 쿨 줄이기**(1안의 −4초) → **추천: v1은 넣지 않는다.** '쓰러뜨리는 카드 → 마무리 카드' 순서 판단을 살리려고. 측정에서 그로기 창 안 드래그 비중이 평소보다 안 높으면 −2초부터 시험.
4. **쓰러질 때 쫄 1초 기절**(1안의 충격파) → **추천: v1은 연출만.** 보스 발밑을 비워 주는 효과는 좋지만, 아직 재지 않았고 엘리베이터 그림자 아이(4~6마리)를 너무 쉽게 만든다. 필요하면 조절값으로 켠다.
5. **사람 수에 따라 최대치 키우기**(1 / 1.4 / 1.8) → **추천: 예.** 사람 3명(이미 쉬움)이 너무 자주 쓰러뜨리지 않게. 측정에서 차이를 벌리지 않았다(+1.3%p).
6. **보스별 최대치 배수**: 5층 0.8(배우는 자리), 10·15층 1.0, 20층 1.1 → **추천: 그대로.**
7. **반복 그로기**: 끝난 뒤 10초 잠금 + 매번 최대치 +50% → **추천: 그대로.** 최악 파티에서도 보스가 누워 있는 시간 약 15%.
8. **힐러 드래그(클레릭·메딕)는 0점** → **추천: 0점.** 힐러의 값은 회복이고, 쓰러뜨린 뒤 '안전한 교체' 카드가 된다. 힐러 파티가 너무 못 쓰러뜨리면 5점으로.
9. **그로기 중 보스 쿨 멈춤 + 일어난 뒤 1.5초 쉼** → **추천: 예.** 일어나자마자 패턴이 몰려오는 것을 막는다. 일반 몬스터는 4차 규칙 그대로(쿨 흐름).
10. **중간 보스** → **추천: v1에 안 넣는다.** 이미 기절이 걸린다. 일반층이 보스층보다 심심하다는 말이 나오면 '비틀'(게이지 50, 2.5초, ×1.3) 또는 '준비 동작을 끊으면 2초 ×1.25'를 2차로.
11. **기절 없는 파티(원거리·서포트)가 가장 덜 도움 받음** → **추천: 13차는 그대로 두고**, 8차의 파티 구성 문제와 같이 다시 본다.
12. **진동**(쓰러질 때 `navigator.vibrate(40)`, 안드로이드만) → **추천: v1은 끔.** 나중에 설정으로.
13. **광폭화** → **추천: 광폭화 뒤에도 그로기 규칙 같음, 그로기 중에도 광폭화 타이머 흐름.** 그로기는 역전 수단이지 시간 연장이 아니다.
14. **페이즈** → **추천: HP 기준은 바로 넘어가고(◆ 바로 바뀜), 새 패턴과 배너는 일어난 뒤.** 어떤 페이즈도 건너뛰지 않고, 배너가 폭딜 장면을 가리지 않는다.
15. **쓰러뜨린 사람 보상**(예: 궁극기 +10%) → **추천: 없음.** 이름 표시와 결과 화면 기록만. 보상이 있으면 협력 대신 막타 경쟁이 된다.
