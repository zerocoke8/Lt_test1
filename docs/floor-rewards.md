## 한 줄 요약

층 보상이 12계열에서 **93계열**로 늘어납니다. 아이디어 87개 중 86개를 넣고(1개는 지금 카드에 합침), 1개만 뺐습니다. 등급은 4개(전설 신설), 보상마다 **시너지 태그**가 붙고 같은 태그 3개를 모으면 **모음 보너스**. 보상 화면에 **다시 뽑기**(향 한 자루)와 **지명권**(대상 캐릭터 직접 고르기)이 생깁니다.

- 괴담 방의 보상 뽑기는 지금 확률 그대로(전설 0).

### 3장 구성

- 3장은 서로 다른 계열.
- **1장은 기본 12계열**에서(숫자 성장 지킴), **2장은 새 계열**에서.
- 교체 보장: 3장 중 최소 1장은 #등장 / #퇴장 / #교대 / #저스트 태그. 없으면 3번째 카드를 같은 등급의 그런 카드로 바꿈.
- 저주 카드(#저주) 최대 1장, 뽑힐 무게 ×0.6. 협동 카드(#협동) 최대 1장, 혼자 하기(사람 1명)에서는 무게 ×0.7. 두 상한은 **카드 계열의 태그**로 셈(빚쟁이·상자 속 상자·욕심쟁이·피의 서약·최후의 1인 포함, 직업 특기 카드는 안 셈), 전설 칸도 같음(기획 17차 리뷰).
- 태그 끌림: 어떤 태그를 2개 가졌고 아직 3개가 아니면 그 태그 카드 무게 ×1.5.
- 나오지 않는 카드: 파티에 맞는 직업이 없는 카드 / 가진 「한 번만」·전설 / 유물 「교대의 깃발」을 가졌을 때의 교대 폭발 / 효과가 아직 남은 상자·빚·욕심 / 다음 층이 보스층일 때의 상자 속 상자·욕심쟁이(클래식) / 동료가 모두 탈락했을 때의 협동 카드 / 바꿀 일반 보상이 없을 때의 금박 부적 / 내 화상 수단(마법사, 그을린 발자국, 불붙은 손, 원정 무기 「그을린 발자국」)이 없을 때의 연쇄 화상 / 합이 이미 50%인 펫 훈련(기획 17차 리뷰).

## 시너지 태그와 3개 모음 보너스

보상마다 태그 1~2개. 클래식 유물도 태그 1개씩 셉니다(메아리 인장 #등장, 교대의 깃발 #퇴장, 선봉의 투구 #등장, 사냥꾼의 표식 #교대, 불사조 깃털 #생존, 야수의 목걸이 #펫, 광기 사냥꾼 #보스, 흡혈의 잔 #생존). 같은 카드를 두 번 고르면 2개로 셉니다. 보너스는 태그마다 **한 번만**(6개라고 두 번 받지 않음).

| 태그 | 3개 모음 보너스 |
|---|---|
| #등장 | 등장·착지 보상의 위력·범위 +20%, 등장 무적 +0.3초 |
| #퇴장 | 퇴장 보상의 범위 +20%, 남는 것(장판·안개·포탑·잔상·지뢰) 지속 +1초 |
| #교대 | 모든 캐릭터 재등장 쿨 −1초 (최소 4초) |
| #저스트 | 저스트 창 +0.1초, 저스트 드래그 보너스 +50% → +75% |
| #궁극기 | 궁 게이지 충전 +12% |
| #펫 | 펫 쿨 −10%, 펫 효과 +10% |
| #상태이상 | 내가 거는 해로운 상태 지속 +20% (그로기 점수에는 X) |
| #보스 | 보스·중형보스에게 주는 피해 +10% |
| #생존 | 받는 회복·보호막 +15% |
| #공격 | 치명타 피해 +25%p |
| #저주 | 저주 카드의 HP 대가 절반 |
| #협동 | 다른 플레이어 필드 캐릭터 반경 5 안이면 공격력 +10% |
| #성장 | 층(단계) 시작 때 내 캐릭터 3명 궁 게이지 +10% |

- 보상 화면: 카드의 태그 칩 「#퇴장 ●●○ 2/3」. 이 카드로 3개가 되면 금색 「3/3 완성!」 + 보너스 한 줄.
- 고른 순간 금색 도장 「#퇴장 3개 모음!」 1.2초 + 소리. 다음 층 시작 때 위쪽 알림 한 번.

## 다시 뽑기 · 지명권

### 다시 뽑기 「향 한 자루」

- 런 시작 때 **1개**, 보스를 깰 때마다 **+1**(클래식 5·10·15층, 원정 3·6·9단계), 보상 「여분의 향」 +2. **최대 5개**.
- 누르면 3장을 모두 새로 뽑음. 방금 보인 계열은 이번 새 뽑기에서 빠짐.
- 유물 화면(보스층)에서는 숨김. 원정은 런 동안 이어짐(수령하면 사라짐).
- 멀티: 각자 자기 개수. 시간은 늘지 않음. 남은 시간 3초 이하면 누를 수 없음(버튼이 꺼지고, 서버도 「시간이 얼마 안 남아 다시 뽑을 수 없어요」로 거절).
- 봇은 다시 뽑기를 쓰지 않음.
- 카드 뽑기와 다시 뽑기는 「시드 + 층 + 플레이어 + 몇 번째 뽑기」로 만든 **따로 난수**를 씀. 누가 다시 뽑아도 전투 결과와 다른 사람의 카드는 바뀌지 않음.

### 지명권 (대상 직접 고르기)

- 캐릭터에 붙는 카드(드래그스킬 강화·확장, 빠른 교대, 등장 보호막, 일반스킬 가속, 궁극기 강화, 이중 장전)는 **항상 대상을 고를 수 있음**. 카드 아래 「누구에게?」 + 내 초상화 3개. 이 줄(글자·틈 포함)을 누르면 카드를 고르지 않음 — 초상화는 줄을 나눠 가져 누르기 쉬움(기획 17차 리뷰).
- 기본 대상이 미리 골라져 있어 「선택」 한 번이면 끝. 기본 대상 = 카드가 좋아하는 직업 순서(아래) 중 이번 런에서 필드에 가장 오래 있던 캐릭터(같으면 앞 칸).
  - 드래그 강화·확장, 빠른 교대, 이중 장전, 궁극기 강화: 원거리딜러 > 근접딜러 > 탱커 > 서포터 > 힐러
  - 등장 보호막: 탱커 > 근접딜러 > 원거리딜러 > 서포터 > 힐러
  - 일반스킬 가속: 힐러 > 서포터 > 원거리딜러 > 근접딜러 > 탱커
- 「직업 특기」 카드: 제시할 때 내 파티의 직업 하나가 정해져 「탱커 특기」처럼 나옴. 다른 캐릭터 초상화를 누르면 **그 캐릭터의 직업**으로 바뀜(같은 직업 초상화가 함께 빛남). 효과는 그 직업의 내 캐릭터 전원에게. 카드 글이 90자를 넘으면(영웅) 아래 단계는 이름만 쓰고 새 단계만 풀어 씀(「탱커 전원 · 육중한 착지 · 버려진 방패 + 짚 인형: …」), 내 빌드 창에는 전부(기획 17차 리뷰).

### 그 밖의 화면 규칙

- 멀티 보상 시간 20초 → **30초**. 시간이 다 되면 무작위 대신 **봇과 같은 점수로 고른 카드 + 기본 대상**. 시간 줄에 「안 고르면 '교대선'을 골라요」.
- 욕심쟁이 계약서: 다음 화면에 카드 4장, 2장 고름(「하나 더 고르세요 (1/2)」). 그다음 화면은 평소대로(계약서를 고른 화면이 대가 — 총 개수는 그대로, 기획 17차 리뷰). 4장 화면에서는 「누구에게?」 글자 없이 초상화만.
- 빚쟁이의 방문: 건너뛰는 층은 화면 없이 알림 「빚 · 이번 보상 없음 (1층 남음)」.
- 상자 속 상자: 다음 화면 부제 「상자 효과 · 등급 한 단계 ↑」.
- **내 빌드** 창(보상 화면 왼쪽 위 칩, 일시정지 메뉴 목록 맨 위, 원정 로비 버프 목록): 남은 다시 뽑기 / 태그 칩 13개(완성은 금색 + 보너스 문구) / 보상 목록(파티 → 직업 → 캐릭터별 → 협동, 같은 것은 「공격력 강화 ×3 · +38%」처럼 합침) / 흔적·유물.
- 전투 중 발동 표시: 그 캐릭터 머리 위 작은 알약에 태그 아이콘만(글자 없음) 0.9초. 0.25초 안의 발동은 합침(아이콘 최대 3 + 「+N」), 캐릭터당 1개, 화면 전체 4개, 같은 보상은 2초에 1번. 계속 쏘는 효과는 처음만. 내 캐릭터만(다른 사람이 준 협동 효과는 그 사람 색 테두리로). 「저스트!」가 뜨는 순간엔 0.3초 늦게, 아래쪽에. 드래그스킬 이름 같은 말풍선과 겹치면 그 위로(위에 자리가 없으면 아래로) 비킴(기획 17차 리뷰).

## 공통 안전장치

- 보상으로 생기는 추가 피해(에너지탄, 폭발, 교대선, 잔상, 도플갱어, 여운, 충격파, 포탑, 지원사격 등)는 **그로기 게이지를 채우지 않음**. 기록은 「유물」 피해. 드래그를 한 번 더 쏘는 것(도플갱어, 갈래 사격, 두 갈래 손길)도 「유물」 피해라서 드래그 적중이 아님: 그로기 보스 ×2 대신 ×1.5, 돌발 괴담 약점 ×2 없음, 불붙은 손·홀린 자 같은 드래그 적중 효과 없음(기획 17차 리뷰).
- 그로기를 늘리는 보상(그로기 낙하, 파쇄자, 붉은 달)은 서로 곱하되 시전 1번에 **최대 ×2**.
- 게이지를 바로 채우는 보상(합동 의식, 삼인 분향)은 그로기 중·잠금 중엔 안 들어가고, 한 번 쓰러질 때까지 보상으로 들어가는 양은 **최대 30%**.
- 보상의 **받는 피해 감소**(육중한 착지, 버려진 방패, 인수인계 탱커, 엄호 교대, 최후의 1인, 치고 빠지기 제외)는 모두 합쳐 **최대 −50%**. 기본 방어와 「방어 태세」는 따로.
- 재등장 쿨을 줄이는 모든 효과는 마지막에 **최소 4초**. 예외: 출근 도장(0초, 층당 2~3번), 저스트 교대 할인(결과 최소 2.4초).
- HP 대가는 HP를 1 아래로 내리지 않음. 대기석 회복(메딕 간호, 응급 후송)과 같이 가지면 서두르는 대가·피의 등장의 대가 2배.
- 소환·장판 상한(플레이어별, 넘치면 가장 오래된 것이 사라짐): 잔상 계열(잔상·도플갱어 분신·둘이서) 합쳐 2 / 보상 포탑 1 / 지뢰 2(희귀 3) / 짚 인형은 퍼펫티어 종이 인형과 상한 공유(종이 인형 2개면 짚 인형이 안 나옴) / 보상 장판(발자국·안개·방패·잔향) 합쳐 4.
- 상태 복사(바통 터치·인수인계)는 허용 목록만: 공격력 증가, 가속, 방어 증가, 재생, 흡혈, 범위 증가. 정지·조종·도발은 절대 복사 안 함.
- 무작위는 모두 시드 난수(동전 던지기, 직업 지정, 뽑기).
- 장비(원정)와 같은 효과(등장 에너지탄, 교대 폭발, 그을린 발자국, 처형 착지, 등장 보호막, 치유의 잔향, 응급 후송, 버려진 방패, 빠른 교대, 교대 충전, 일반스킬 가속, 오래 쉰 자의 분노): 둘 다 있으면 **한 번만** 터지고 위력은 더하고, 대상 수·반경은 큰 쪽.
- 「두 번」 = 같은 계열을 또 골랐을 때. 따로 적지 않았으면 위력·% 숫자는 더하고, 반경·지속·대상 수는 큰 쪽.

## 보상 전체 표

읽는 법: 숫자는 「일반 / 희귀 / 영웅 / 전설」 중 있는 등급만. 대상: 파티 = 내 캐릭터 전원, 지명 = 고른 캐릭터 1명, 직업 = 그 직업의 내 캐릭터, 팀 = 다른 플레이어 캐릭터까지. 「1번만」 = 한 번 가지면 다시 안 나옴. 공 = 그 캐릭터 공격력.

## 멀티·봇·원정에서

- **멀티**: 각자 자기 화면에서 고름(다시 뽑기·지명권도 각자). 협동 보상의 효과는 팀에게. 아군에게 닿는 장판·보호막은 다른 플레이어 캐릭터에게도 닿음(지금 회복 장판과 같은 규칙). 서버가 판정, 보상 시간 30초. 시간이 다 돼 서버가 대신 골랐으면 전투로 돌아갈 때 「시간이 다 돼서 「…」을 받았어요」 알림(기획 17차 리뷰).
- **봇이 고르는 법** (사람이 시간 안에 못 골라도 같은 규칙):
  - 점수 = 등급 점수 × 계열 봇 무게 × 태그 보정. 같으면 시드 난수.
  - 등급 점수: 일반 1 / 희귀 1.6 / 영웅 2.4 / 전설 2.6(기획 17차 리뷰: 3.2 → 2.6 — 전설이 희귀·보통 영웅은 이기지만 영웅 기본 보상 2.88은 못 이김, 재 보니 영웅 기본이 전설의 2~5배).
  - 계열 봇 무게: 숫자형(기본 12계열) 1.2, 자동 발동형 1.0, 위치·타이밍이 필요한 것(교대선, 맞교대, 준비 즉시, 연쇄 교대, 그로기 낙하, 주인 냄새, 합동 의식, 손 내밀기, 피의 서약) 0.6, 저주·위험 0.5, 경제형(상자·빚·욕심·여분의 향) 0 = 고르지 않음. 빈자리의 대타는 0.3(기획 17차 밸런스: 대타가 같은 공격 속에 나와 손해).
  - 태그 보정: 그 태그를 이미 2개 가졌으면 ×1.3.
  - 대상은 기본 대상 규칙. 봇은 다시 뽑기를 안 씀.
- **원정**: 「층」 = 「단계」. 보상 화면은 일반 단계 뒤에만(보스 단계는 지금처럼 보상 화면 없음). 런에 저장되는 것: 보상 목록, 남은 다시 뽑기, 손톱 단계 수, 촛불 처치 수, 빚·상자·욕심 남은 것, 이중 장전 충전, 두 번 차는 게이지 값(최대 2). 지난 런은 그대로 읽힘(다시 뽑기 없으면 1개로 시작).
