# 드래그스킬 밸런스 (2026-10-04, 2차)

> 기획 요청: "드래그스킬 위력 밸런스 맞춰줘. 물론 데미지 말고 다른 기능들도 있으니 꼭 데미지를 다 맞출 순 없을 것 같아. 데미지 말고 다른 기능이 없거나 범위가 좁으면 데미지가 당연히 더 올라가야 한다고 생각해."
>
> 지켜야 할 기존 결정: 12종 드래그스킬의 **모양과 고정 방향은 그대로** (기획서 16장 표). 드래그스킬 쿨 = 재등장 쿨 **8~12초**, **강할수록 김**.

## 0. 요약

- 1차(같은 날)는 모든 효과를 피해로 바꾼 "가치"를 **쿨 1초당** 같게 맞췄음. 그런데 밸런스 리뷰가 효과를 실제 게임에서 **빼 보고** 잰 결과, 1차 모델은 **기절·둔화·밀기를 실제보다 5~10배** 쳐줬음 (2장). → 모델을 고치고 12종을 다시 맞춤.
- 결과 (현실적인 조준, 1~5층): 쿨 1초당 가치 **97~104%** (평균 = 100%). 다른 시드 24판으로 다시 재도 96~105%.
- 기획 원칙 그대로, 이번에는 **카드의 %가 아니라 실제로 한 명에게 들어가는 피해**로 확인 (공격력 × % × 치명타 기대값):
  - 레인저 **107** (기능 없음) > 블레이드 **97** (가장 좁은 돌진 길 + 짧은 기절) > 거너 **95** (부채꼴 + 넉백) > 버서커 **92** (가장 넓은 부채꼴 + 둔화)
  - 기절·버프·회복이 있는 탱커·서포터는 **20~43**
- 쿨 (강할수록 김): 가디언 11→**10**, 팔라딘 12→**11**, 워든 11→**10**, 클레릭 8→**9**, 크로노 10→**9**초. 시전 1번의 위력 순서와 쿨 순서가 같음: 12초 메이지 216 › 11초 버서커·팔라딘 190~194 › 10초 169~178 › 9초 151~156.
- 게임 전체 페이스는 그대로 (1~4층 ±1초, 보스층 ±2초, 7장).

## 2. 1차 모델에서 틀린 것과 고친 것

리뷰가 한 방법: 같은 판(같은 시드)을 두 번 돌리되, 한 번은 드래그스킬에서 그 효과만 지움 → 파티가 덜 잃은 HP가 그 효과의 실제 값 (`tests/review/drag-ablation.ts`). 2차 수치로 다시 잰 결과 (시드 96개, 시전 1번당):

| 효과 | 1차 모델 | 실제로 빼 보면 (잃은 HP / 받은 피해) | 2차 모델 |
|---|---|---|---|
| 기절 (가디언) | 42 | 8 / 9 | 3 |
| 기절 (팔라딘) | 43 | 5 / 6 | 3 |
| 기절 (크로노, 1차 수치로) | ≈40 | 3 / 4 | 3 |
| 둔화 (버서커) | 21 | 6 / 7 (1차 수치 13 / 15) | 14 |
| 둔화 (바드) | 44 | 14 / 15 | 29 |
| 둔화 (워든, 끌어당김 포함) | ≈49 + 15 | 15 / 27 | 28 + 0 |
| 둔화 + 기절 (크로노) | ≈93 | 8 / 13 | 22 |
| 넉백 (거너) | 11 | −9 / −11 (빼면 오히려 덜 맞음, ±4) | 0 |
| 아군 방어 +25% (팔라딘) | 79 | 56 / 65 | 76 |
| 자기 보호막 (가디언 / 워든) | 93 / 82 | 78 / 65 | 88 / 74 |

왜 틀렸나:
1. **기절·둔화는 대부분 아직 걸어오는 적에게 걸림.** 조준이 적이 가장 많은 무리를 노리는데, 그 무리는 보통 아직 다가오는 중. 기절한 시간 중 적이 자기 대상을 칠 수 있는 거리에 있던 시간은 24~29%뿐.
2. **기절해도 공격 타이머는 돎** (sim 규칙: `src/sim/units.ts`). 기절이 끝나면 바로 침 → 기절은 "다음 공격이 밀린 만큼"만 막음.
3. 적 DPS를 맞는 캐릭터의 **방어 전** 값으로 셌음 (탱커는 방어 30~55%).
4. 밀기·당기기는 적이 곧 다시 걸어오고, 원거리 적은 계속 쏨 → 실제 값 0 ± 3.

고친 모델 (`tests/playtest/drag-bench.ts`, 가중치 `tests/playtest/drag-value.ts`):

| 효과 | 1차 | 2차 |
|---|---|---|
| 기절 | 기절한 적·초 × 적 DPS | 적이 노리는 캐릭터가 사거리 안이고 **공격 타이머가 준비된 채** 기절해 있던 초 × 적 DPS × (1 − 그 캐릭터 방어) |
| 둔화 | 강도 × 초 × 적 DPS | 강도 × **사거리 안에서** 둔화된 초 (기절과 겹친 시간 제외) × 적 DPS × (1 − 그 캐릭터 방어) |
| 밀기·당기기 | 거리 ÷ 이동 속도 × DPS × 0.5 | **0** (거리는 계속 기록) |
| 공격력·공속 버프 | 둘을 더함 | **곱함**: 더 넣은 피해 = 평타 × (1 − 1/((1+공)(1+공속))) + 스킬 × 공/(1+공) |
| 회복·보호막·방어 버프 | 실제로 오른 HP / 막은 양 / 덜 맞은 양 | 그대로 |

2차 모델은 빼 보는 방법과 대부분 시전 1번당 ±15 안에서 맞음 (5장). 바드·크로노 둔화는 아직 10~15 높게 침 (둘 다 같은 캐릭터 3명 파티가 자주 전멸해서 빼 보는 쪽도 ±5로 흔들림).

## 3. 측정 방법

도구: `tests/playtest/drag-bench.ts` (실제 sim을 화면 없이 돌림). 실행: `npx vite-node tests/playtest/drag-bench.ts` (약 1분).

- **나** = 같은 캐릭터 3명으로 편성 → 내 드래그 효과는 전부 그 캐릭터 것. 카드가 준비되면 **4초마다 교체** (기획서: 쿨 8~12초 × 3명 → 3~4초마다 교체), 궁극기는 가득 차고 0.5초 뒤, 펫은 안 씀.
- 다른 2명 = 기본 봇 (가디언·레인저·클레릭 / 블레이드·메이지·버서커).
- **1~5층**: 1~4층 일반층(중형보스 포함) + 5층 보스층. 시드 24개.
- 층 보상은 **드래그스킬과 상관없는 것**을 고름 → 12종을 기본 수치로 비교.
- 조준 3가지 (같은 판에서 비교):
  - **기획자 조준 (목표 기준)**: 적 무리 중심 + 카드 모양을 보고 정한 위치. 방향 스킬은 무리 반대쪽에서 시작 (블레이드 무리 왼쪽 3칸, 버서커 1.6칸, 섀도우 2.2칸, 레인저 2.5칸, 거너 오른쪽 2칸). 클레릭은 다친 아군 무리 중심.
  - **최적 조준**: 봇 조준 (실제 범위로 화면 안에서 적이 가장 많이 맞는 곳).
  - **초보 조준**: 손가락을 무리 한가운데에 놓음.
- 시전 1번마다 **실제로 일어난 것**만 셈 (2장 표). 피해는 화상 틱·늦게 떨어지는 유성·장판 포함, 넘친 피해(오버킬) 제외. 회복은 넘친 회복 제외, 보호막은 실제로 막은 양.

### 가치 모델 (피해로 환산)

**가치 = 피해 + 회복 + 보호막 흡수 + 방어 버프로 덜 맞은 피해 + 기절로 막은 피해 + 둔화로 막은 피해 + 버프로 더 넣은 피해 + 0.5 × 쿨 감소 초 × 평균 가치/초**

| 가중치 (`VALUE_WEIGHTS`) | 값 | 근거 |
|---|---|---|
| `hp` (HP 1 지킴 = 피해 몇) | 1.0 | 파티가 준 피해는 받은 피해의 약 2.8배 → HP 1의 값은 0(아무도 안 위험)~2.8(모든 HP가 승패를 가름) 사이. 런이 20층까지 가므로 중간 1:1. 리뷰가 사망·전멸로 잰 값은 약 0.85 → 1.0은 살짝 후한 쪽 |
| `stun`, `slow` | 1.0 | 위의 "실제로 막은 피해"를 그대로 |
| `displace` | 0 | 2장 |
| `buff` | 1.0 | 더 넣은 피해 = 피해 |
| `cdSec` (크로노 쿨 감소 1초 = 평균 쿨 1초당 가치 × 이것) | 0.5 | 아래 |

크로노 쿨 감소의 실제 값은 **교체 리듬에 따라 0~1** (파티 크로노·블레이드·메이지, 1~3층, 24판, 직접 잼):

| 교체 리듬 | 크로노 1번당 다른 카드가 더 나온 횟수 | 가치로 |
|---|---|---|
| 4초마다 (기획서 기준) | 0.03 | ≈ 0 (카드가 어차피 12초마다 돌아옴) |
| 2초마다 | 0.39 | ≈ 70 (`cdSec` ≈ 1.0) |
| 준비되자마자 | 0.36 | ≈ 65 |

→ 0.5 = 두 플레이 방식의 중간. 4초 리듬 플레이어에게 크로노는 약 76%, 빠르게 교체하는 플레이어에게는 약 118% (8장).

목표: **가치 ÷ 쿨**이 12종 모두 같음 (±15%). 범위(얼마나 많이 맞히는지)는 따로 점수를 주지 않음: 실제로 맞힌 적 수가 피해·기절에 이미 들어 있음.

- **메이지 = 보스 특화**: 유성 5개가 반경 3 보스에 다 맞아서 보스층에서 시전 1번 340 (레인저 176, 블레이드 159, 거너 155). 1~5층 평균으로는 맞지만 보스층(5·10·15·20층)만 보면 메이지 약 2배. "큰 적에게는 여러 곳 공격이 다 맞는다"를 메이지·섀도우의 개성으로 둠. 맞추고 싶으면 데이터만으로는 안 되고 규칙 추가가 필요 (예: 한 번 시전에 같은 적은 최대 3번) → 원하면 알려 주세요.
- **기절은 공격 타이머를 멈추지 않음** (sim 규칙). 기절이 "다음 공격을 밀기"만 해서 값이 작음. 타이머를 멈추게 바꿔도 리뷰 측정으로 팔라딘만 5 → 11 정도 (대부분 걸어오는 적에게 걸리기 때문). 규칙은 안 바꿈.
- **크로노 쿨 감소는 플레이 리듬에 따라 0~70**: 4초 리듬이면 76%, 빠르게 교체하면 118% (3장). 실제 플레이테스트로 사람들이 어떤 리듬인지 보면 `cdSec` 가중치를 정할 수 있음.
- **층이 늘면 다시 재야 함**: 1~10층으로 넓히면 89~113% (4-3). 20층까지 가면 탱커·클레릭이 더 세짐.
- **벤치의 같은 캐릭터 3명 파티**: 크로노×3은 24판 중 13판, 바드×3은 8판이 5층 전에 전멸 (1~10층: 16판씩). 시전 1번당 평균으로 비교하므로 영향은 작지만 그 둘의 5층 표본이 적음.
- **회복 가중치 1.0은 살짝 후함** (리뷰가 사망·전멸로 잰 값 ≈ 0.85). 0.85면 클레릭 약 92%.
- **바드 버프는 아군이 띠 안에 있어야 함**: 벤치에서 평균 1.0명 (대부분 바드 자신). 멀티에서 붙어 싸우면 더 셀 수 있음.
- **안 센 효과**: 클레릭 정화, 블레이드 돌진으로 위치가 바뀌는 것, 워든이 적을 모아서 다른 스킬이 더 맞는 것, 몬스터 스킬(오우거 내려찍기 등)을 기절로 끊는 것.
- **일반스킬·궁극기·패시브는 이번에 안 건드림** (드래그스킬만).
