# 보스 20종 (기획 20차, 2026-10-12 — 형태 4가지 + 패턴 다양화)

보스 레이드(`docs/boss-raid.md`)에 나오는 보스 전부. 19차(2026-10-11)의 20종을 그대로 두고, **새 16종의 형태와 패턴을 다시 만듦**. 기존 4종(엘리베이터 · 야근의 군주 · 수술실 원장 · 심연의 감시자)은 수치·그림·소리·자리 그대로 → 클래식 탑은 한 틱도 안 바뀜.

**상태: 구현됨 (2026-10-12).** 2장의 숫자 표는 지금 데이터에서 뽑은 것(`npx vite-node tests/review/boss-table.ts write`). 4장은 보스별 설명 — 숫자는 전부 「대략」(디자이너가 해 본 뒤 고침). 통합 때 명세에서 바꾼 것은 1-5에, 결정 요약과 플레이 뒤 질문은 `docs/game-design.md` §33에.

디자이너 피드백(19차 플레이 뒤): ① 보스가 전부 맨 위 가운데 같은 자리에 나와서 겹쳐 보이고 느낌이 같음 ② 보스가 못 움직이니 장판도 다 비슷함 ③ 거꾸로 뜬 달 · 대답하는 연필의 「안전한 자리 찾기」가 좋았음, 연필은 맵 전체에 종이가 깔리고 연필이 돌아다니는 모습을 원함. → 형태부터 바꾸고(1장), 그 위에 패턴을 다시 얹음(3 · 4장).

**숫자는 이번에도 「대략」.** 고치는 도구는 그대로: ① 보스마다 켬/끔 한 줄(`raid: false`) ② 배율 슬라이더(19차 4개 + 「보스 이동 속도 배율」 1개) ③ 디버그 「보스 고르기」 ④ 숫자는 전부 데이터에만 두고 2장 표로 그대로 뽑음.

## 1. 형태 4가지

### 1-1. 네 형태

| | 고정형 `fixed` | 배회형 `roaming` | 자리 이동형 `relocating` | 전장형 `arena` |
|---|---|---|---|---|
| 느낌 | 장소 자체가 보스 | 맵을 걸어 다니는 괴물. 공격이 몸에서 나감 | 정해진 3~4자리를 옮겨 다님. 자리마다 공격 방향이 바뀜 | 맵 전체가 보스의 무대. 작은 「핵」이 그 위를 다님 |
| 나오는 자리 | 맨 위 가운데 (12, −1.2) — 19차 그대로 | 맵 안 `spawn` (기본 (12, 4)) | `spots[0]` | `spawn` (= 길의 첫 점) |
| 몸 반지름 | 3 | 1.4~1.7 | 1.6~1.8 | 1.3~1.8 |
| 움직임 | 없음 | 걸음 (`move`: 쫓기 / 거리 두기 / 순찰) | 서 있다가 「이동」 스킬로 순간 이동 | 정해진 길(`path`)을 돌거나 천천히 쫓음 |
| 기절 · 넉백 · 끌기 · 묶기 · 속박 | 면역 | 면역 (「무거움」) | 면역 | 면역 (「무거움」) |
| 도발 | 안 통함 | **통함** (도발한 탱커를 쫓아옴) | 안 통함 | 안 통함 |
| 기본 공격 | 원거리(사거리 40) | 근접(사거리 0.9~1.2) 또는 원거리 | 원거리(사거리 40) | 근접 또는 원거리 |
| 그림 | 위쪽 큰 세트(19차 방식) | 맵 안의 몸(캐릭터와 앞뒤 순서를 맞춰 그림) | 맵 안의 몸 + 바닥의 자리 표시 | 바닥 전체 그림 + 작은 몸 |

- 움직이는 몸의 중심은 **상자 x 2~22, y 3~10** 안에만 있음(위 HUD 보스 박스와 아래 카드를 안 가림). 돌진 끝점 · 이동 자리 · 순간이동 자리도 이 상자 안.
- 「무거움」: 캐릭터와 겹치면 캐릭터만 밀려남. 보스는 어떤 스킬로도 안 밀림.
- 맞는 판정은 네 형태 모두 지금처럼 「몸 원에 닿으면 맞음」. 근접 캐릭터는 걸어가서 때리고, 원거리는 쏨.
- 움직이는 보스는 층 시작 1초 동안 등장 자세로 서 있다가 움직임.
- 패턴을 준비하는 동안은 멈춰 서고 **보는 방향도 굳음**(여러 조각이면 마지막 조각까지). 예외는 보스 데이터에 적음(커피 머신의 기본 공격, 달은 늘 움직임).
- 그로기: 그 자리에 멈추고 방향도 굳음. 광폭화: 공용 `ENRAGE` + 걸음 · 몸 돌리기 ×1.25.

### 1-3. 공통 틀

- 수치는 1층 기준. HP 6,800~9,000 · 공격 28~32 · 방어 0.2 · 공속 0.5~0.6. 층 배율 × 레이드 배율이 곱해짐(19차 그대로).
- 스킬 3개 + **페이즈 1개**(HP 45~50%: 이름 + 패턴 1개 추가 + 공속/쿨 배율). 광폭화는 공용 `ENRAGE`. 그로기 게이지 전부 있음. 쿨 7초 이상, 예고 0.8초 이상, 짧은 예고(`telegraphLead`)도 0.9초 이상.
- 「피해 2.2」 = 보스 공격력 × 220%. 좌표는 아레나 기준(가로 0~24, 세로 0~12, 위가 0).
- **모든 패턴의 답은 교체**: 위치(어디에 꺼내나)와 타이밍(언제 빼나 — 저스트 교대). 바닥에 **남는 장판**만 캐릭터가 스스로 돌아감(3장 N8).
- 패턴 id 머리말은 그대로(`cm_` `wd_` `kr_` `re_` / `sh_` `cf_` `dm_` `em_` / `md_` `xr_` `df_` `eb_` / `td_` `ta_` `ap_` `im_`). 소리 · 팁 · 예고 덧그림이 패턴 id로 찾음.
- 보스 데이터에 `signature: '<패턴 id>'`를 적음 = 대표 패턴(패턴 시트 · 첫 팁).

### 1-4. 데이터의 칸 (형태마다 예시)

보스 항목(`src/data/bosses/<구역>.ts`)에 아래 칸을 더함. **`form`이 없으면 고정형 = 19차와 100% 같음**(기존 4종은 새 칸이 하나도 없음). 공용 기본값은 `src/data/bosses/forms.ts`.

```ts
// 배회형 — 쫓기 (세탁기)
{ form: 'roaming', radius: 1.6, spawn: { x: 20, y: 3.5 },
  stats: { ...moveSpeed: 2.2, range: 0.9 }, basic: { kind: 'melee', splashRadius: 1.2 },
  move: { mode: 'pursue', target: 'farthest', retarget: 5 }, signature: 'wd_roll' }

// 배회형 — 순찰 + 발자국 (커피 머신)
{ form: 'roaming', radius: 1.5, spawn: { x: 4, y: 3 },
  move: { mode: 'patrol', waypoints: [{ x: 4, y: 3 }, { x: 20, y: 3 }, { x: 20, y: 9.5 }, { x: 4, y: 9.5 }], dwell: 0.6 },
  trail: { every: 1.2, max: 14, radius: 1.1, duration: 8, tickInterval: 0.5, look: 'coffee',
           effects: [{ kind: 'damage', amount: 0.3 }, { kind: 'status', status: 'slow', duration: 1, value: 0.3 }] } }

// 배회형 — 앞 방패 · 뒤 약점 (파쇄기)
{ form: 'roaming', radius: 1.7, spawn: { x: 4.5, y: 8.5 }, move: { mode: 'pursue', turnRate: 60 },
  guard: { frontArc: 140, frontMult: 0.5, backArc: 120, backMult: 1.6 } }

// 자리 이동형 (회의)
{ form: 'relocating', radius: 1.7, stationary: true,
  spots: [{ x: 21, y: 6, facing: 'left' }, { x: 12, y: 10, facing: 'up' }, { x: 3, y: 6, facing: 'right' }, { x: 12, y: 3, facing: 'down' }] }   // 첫 자리 = 시작 자리

// 전장형 (연필)
{ form: 'arena', radius: 1.4, spawn: { x: 12, y: 4 }, move: { mode: 'pursue' }, stats: { ...moveSpeed: 0.8, range: 1 },
  stage: { floor: 'paper', marks: [{ id: 'yes', x: 5, y: 6, r: 3.2, label: '예' }, { id: 'no', x: 19, y: 6, r: 3.2, label: '아니오' }] } }
```

### 1-5. 통합 때 명세에서 바꾼 것 (2026-10-12)

만들어서 폰 화면으로 보니 명세대로는 디자이너 지적이 덜 풀리는 곳이 있어서, **데이터 몇 줄**을 바꿈. 전부 숫자 · 자리라서 다시 바꾸기 쉬움.

| 무엇 | 명세 | 지금 | 왜 |
|---|---|---|---|
| 등장 자리 | 뽑기 기계 (12, 3.5) · 파쇄기 (12, 3) · 물탱크 (12, 3) | 뽑기 기계 **(4, 5.5) 왼쪽 벽** · 파쇄기 **(4.5, 8.5) 왼쪽 아래** · 물탱크 **(19.5, 8.5) 오른쪽 아래** | 움직이는 14종 중 6종이 여전히 맨 위 가운데(가로 12)에서 나왔음 → 지금은 연필 1종만 |
| 자리 이동형의 첫 자리 | 회의 · 투시 촬영기 모두 위쪽 자리(12, 3) | 회의 **오른쪽 자리 (21, 6)** · 투시 촬영기 **왼쪽 정거장 (3.5, 6)**. 도는 순서(시계 방향)는 그대로 | 같은 이유. 촬영기는 첫 스캔 줄이 맵을 가로로 끝까지 쓸고 감(위에서 시작하면 줄 9개 중 4~5개만 맵 안) |
| 제세동기의 걸음 | 가까운 캐릭터를 쫓음(이동 1.5) | **세 자리 (18, 4) → (6, 4.5) → (12, 9)를 돎**, 자리마다 3초 섬, 이동 1.8. 도발하면 탱커를 따라옴 | 파티가 먼저 달라붙어서 한 전투에 한 칸도 안 움직였음(지금 19칸쯤) |
| 처음 보는 방향 | 아래 | 걸어 다니는 보스는 **맵 가운데 쪽**을 보고 나옴 | 옆 · 아래에서 나올 때 벽을 보고 서 있지 않게 |
| 「자리 이동형」 칩 | — | 글자를 조금 작게 | 오른쪽 위 단추와 겹쳤음 |

그대로 둔 것(플레이 뒤 정함): **천둥 안테나**는 구석으로 달아난 뒤 거의 안 움직임(한 전투 7칸쯤). 달아나는 성격을 지키려고 그대로 뒀고, 제세동기처럼 「옥상을 도는 길」로 바꾸는 건 한 줄(§33 질문 13).

### 1-6. 검토 뒤 바꾼 것 (2026-10-12, 기획 20차 점검)

**슬라이더가 새 패턴에 닿는 방식**:

- 「보스 예고 시간 배율」 ×T: 모든 조각의 `delay` · `telegraphLead`에 ×T(19차 그대로) → 돌진 예고, 자리 이동 예고, 빛줄기 · 스캔 줄의 조각 간격(= 도는 속도)이 같이 늘거나 줄어듦. 장판 시간 · 걸음 · 몸 돌리기 · 쿨 · `charge.recover`는 그대로.
- 「보스 범위 크기 배율」 ×A: 기울인 띠의 길이와 폭, 돌진 폭, 흔적 반지름(간격은 그대로)에 ×A. **안전 구멍(고리 안쪽)은 그대로**(19차 규칙) → 안전한 자리는 안 줄어듦. **번호 없는 서랍의 칸도 그대로**(`fixedArea`, 늘 12 × 4). 자리(`spots`) · 아레나 좌표는 안 바뀜.
- 「보스 이동 속도 배율」 ×M (새로): 형태가 있는 보스의 걸음 속도에 ×M(돌진 · 순간이동 제외). 기본 1.
- 셋 다 중형보스 · 일반 몬스터 · 쫄 · 캐릭터에는 안 닿음.

## 5. 그림 메모

단위: 맵 1칸 = 가로 약 53 px · 세로 약 29 px(1280×720 기준, 폰은 ×0.54). 그림 규칙은 19차 그대로(그라데이션 · `shadowBlur` · `Math.random` 금지).

### 5-1. 움직이는 몸 (배회 · 자리 이동 · 전장형의 핵)

- **크기**: 반지름 1.5칸 기준 몸 상자 폭 150 px × 높이 최대 140 px(폰에서 약 81 × 76 px). 낮은 몸(파쇄기 · 병상) 150 × 85, 가는 몸(연필 · 안테나 · 커피 머신) 폭 100 이하 · 높이 170까지.
- **그리는 순서**: 캐릭터와 같은 목록에 넣어 세로(y) 순서로 그림 → 보스보다 앞에 있는 캐릭터는 보스 위에, 뒤에 있으면 보스 뒤에. 보스 뒤에 가린 캐릭터는 **플레이어 색 실루엣**으로 비쳐 보임. 이름표 · 체력 막대는 늘 맨 위.
- **발밑**: 진한 그림자 + 보스 고리(빨강 두 줄, 반지름 × 1.2). 머리 위 ▼ 표시는 등장 · 자리 이동 도착 · 돌진이 끝난 뒤 1.5초와 카드를 끄는 동안만 진하게.
- 보스 이름 · 체력 · 패턴 이름은 지금처럼 위쪽 막대에만(몸 위에는 체력 막대 없음).
- **자세 5개**: 대기 `idle` · 걷기 `walk` · 준비 `windup` · 공격 `attack` · 그로기 `groggy`. 보스별 그림은 「오른쪽을 보는 그림」만 그리고, 공통 틀이 좌우 뒤집기(0.25초 안에는 다시 안 뒤집음) · 걷기 흔들림 · 준비 때 부풀기 · 돌진 잔상 · 그로기 기울임과 물 빠진 색 · 광폭화 붉은 물 · 등장(바닥에서 솟음) · 퇴각(가라앉음)을 처리.
- 한 자세 그리기 220번 이하, 글자 없음(뒤집히면 거꾸로 보임), 6 px보다 작은 장식 금지.
- 그림이 아직 없는 보스는 「보스 색 덩어리 + 눈 하나」 임시 몸으로 나옴(게임은 돌아감).
- 그로기 별 · 「그로기!」 도장 · 금색 고리 · 단일 대상 조준선은 **보스 발 위치** 기준으로.

## 6. 소리

- 틀은 19차 그대로: 보스별 `voice` 행(`src/audio/synth/bossVoices/<구역>.ts`) `{ base, motif, timbre, kinds }`, kind 15종(doors countdown papers stamp summon blades gas slice burst beam tentacle ring water static chime), 소리 id `boss.windup.<kind>` / `boss.impact.<kind>`, 처치음 `boss.death.<id>`. 기본음 · 모티프 · 음색은 19차 값 그대로.
