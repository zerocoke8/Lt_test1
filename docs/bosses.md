# 보스 20종 (기획 19차, 2026-10-11)

보스 레이드(`docs/boss-raid.md`)에 나오는 보스 전부. 기존 4종은 수치·그림·소리 그대로(`lore`·`zone`만 추가). 새 16종은 아래 틀을 지킴.

**상태: 구현됨** (20종 데이터·그림·소리, 통합 확인 2026-10-11). 한 장으로 보기: `docs/screenshots/bosses-20.png`(구역마다 한 줄, 보스마다 대기·준비 자세 — 그림만) · `bosses-20-phone.png`(실제 폰 화면: HUD와 파티가 보스 앞에 있는 채로). 명세와 달라진 점은 `docs/boss-raid.md` 12장.

**이번 차수의 숫자는 「대략」임.** 디자이너가 직접 해 본 뒤 보스를 빼거나, 범위 공격의 속도(예고 시간)·범위 크기를 고칠 예정 → 그래서 ① 보스마다 켬/끔 한 줄(`raid: false`) ② 전체 배율 슬라이더 4개 ③ 숫자를 전부 데이터에만 두고 이 문서 2장의 표로 그대로 뽑음(2-1 「숫자 고치는 법」).

## 1. 공통 틀

- 자리: 맨 위 가운데(12, −1.2) 고정, 반지름 3, 기절·넉백·도발·묶기 면역, 기본 공격 원거리(탄 속도 11, 사거리 40).
- 수치는 1층 기준. HP 6,800~9,200 · 공격 28~32 · 방어 0.2 · 공속 0.5~0.6. 층 배율 × 레이드 HP 배율 0.8이 곱해짐.
- 보스 항목의 칸(`src/data/bosses/<구역>.ts`): 이름·수치·스킬·페이즈·그로기·광폭화 + `lore`(괴담 한 줄) · `zone`(구역) · `raid`(없거나 `true` = 레이드에 나옴, `false` = 레이드에서 뺌 — 클래식 탑과는 무관).
- 「피해 2.2」 = 보스 공격력 × 220%. 예고 1.0~1.6초(기존 보스와 같은 띠). 단일 대상 큰 한 방은 저스트 교대 연습용으로 1.4~1.6초.
- 스킬 2~3개 + **페이즈 1개**(HP 45~60%: 이름 + 패턴 1개 추가 + 공속/쿨 배율). 광폭화는 공용 `ENRAGE`(공격 ×1.6 · 공속 ×1.5 · 쿨 ×0.6 · 소환 ×1.5). 그로기 게이지 전부 있음.
- 소리: 패턴마다 kind 하나(기존 12종 doors countdown papers stamp summon blades gas slice burst beam tentacle ring + 새 3종 **water · static · chime**). 준비음·타격음이 같은 kind를 씀. 보스마다 `voice` (기본음 Hz · 모티프 · 음색 토큰). 패턴별 kind는 5장 표.
- 그림: `src/render/bosses/<구역>.ts`에 코드로(기존 `bosses.ts`는 `bosses/classic.ts`로 옮김). 얼굴·눈은 화면 y 100~230(위 HUD 보스 박스 x 424~856·y<100을 피함), 프레임당 캔버스 호출 ≤ 360, `shadowBlur`·그라데이션·`Math.random` 금지.
- 패턴 id는 보스마다 두 글자 머리말(`cm_` `wd_` `kr_` `re_` / `sh_` `cf_` `dm_` `em_` / `md_` `xr_` `df_` `eb_` / `td_` `ta_` `ap_` `im_`) — 소리·팁·예고 덧그림이 패턴 id로 찾으므로 전체에서 겹치면 안 됨.

### 2-1. 숫자 고치는 법 (세밀한 밸런스는 플레이 뒤에)

- **숫자는 전부 데이터에만 있음**: `src/data/bosses/<구역>.ts`의 보스 항목. 코드 속에 숨은 숫자 없음. 아래 표는 그 데이터를 그대로 뽑은 것.
- 표의 칸 ↔ 데이터의 칸: HP `stats.maxHp` · 공격 `stats.atk` · 공속 `stats.atkSpeed` · 그로기 `groggy.threshold` · 페이즈 `phases[].hpBelow / atkSpeedMult / cooldownMult` · 쿨 `cooldown` · 첫 시전 `initialDelay` · 예고 `delay`(조각마다) · 범위 `area` · 피해 `effects[].amount` · 레이드 켬/끔 `raid`.
- **보스 빼기**: 그 보스 항목에 `raid: false` 한 줄. 표의 「레이드」 칸이 「끔」이 되고, 그 자리는 같은 구역의 켜진 보스가 메움(규칙은 `docs/boss-raid.md` 3장). 클래식 탑에는 영향 없음.
- **한꺼번에 조절**(데이터를 안 고치고): 디버그 슬라이더 「보스 예고 시간 배율」·「보스 범위 크기 배율」·「보스 레이드 HP 배율」·「보스 레이드 공격 배율」(`docs/boss-raid.md` 4장). 표의 예고·범위 숫자에 그 배율이 곱해짐.
- 표 다시 뽑기: `npx vite-node tests/review/boss-table.ts write` → 아래 「표 시작 ~ 표 끝」 사이를 데이터에서 그대로 다시 씀(손으로 붙일 필요 없음).
- 읽는 법: 「피해 2.2」 = 보스 공격력 × 220%. 예고 칸에 숫자가 여러 개면 조각이 그 순서로 떨어짐(예: `1.4 / 1.75 / 2.1` = 0.35초 간격으로 쓸고 지나감). 「시작 자리 (x, y)」는 아레나 좌표(가로 0~24, 세로 0~12, 위가 0), 「대상 기준 (x, y)」는 노려진 캐릭터에서 떨어진 칸. 「띠→ 길이 24 · 폭 2.5」 = 왼쪽 벽에서 오른쪽으로 아레나 폭 전체, 두께 2.5.

## 3. 새 규칙 (4개 — 새 코드는 M1·M3뿐, M2·M4는 이미 있는 칸을 보스가 처음 쓰는 것)

**검토 뒤 더한 작은 규칙 5개** (2026-10-11, 자세히 `docs/boss-raid.md` 13장):

- **보스는 「한 조각 여러 타」(`hits`)를 안 씀.** 뒤 타가 예고 없이 대상을 다시 겨누기 때문. 같은 공격을 여러 번 하려면 `repeat(조각, [시간들])`(`helpers.ts`)로 타마다 조각을 둠 → 타마다 예고. 박자(1.2 / 1.7 / 2.2초, 시전 때 자리) · 스팀(1.2 / 1.6초) · 현상(1.6 / 2초, 둘 다 따라옴). 테스트가 막음.
- **등장 무적 중에는 적의 끌기 · 밀기에 안 움직임 — 보스 레이드에서만.** 저스트 교대로 끌기 고리(집게 · 병상 정렬 · 손잡이)나 미는 띠(역주행)를 피하면 정말 빠져나옴. 클래식 탑 · 원정은 예전 그대로(같은 시드 = 같은 판).
- **속박 · 묶기는 필드에 남음.** 캐릭터가 교체로 나가거나 층이 바뀌면 풀림(예전 자리로 끌려가던 버그).
- **자리마다 소환 수 제한 `summon.spotCap`.** 오류 창은 자리마다 1개: 살아 있는 자리는 건너뛰고 부서진 자리만 다시 열림(광폭화의 소환 ×1.5도 1개).
- **보스가 자기에게 쓰는 스킬(M1)은 광폭화의 쿨 ×0.6을 안 받음**(회의 연장 · 심폐소생).

그 외 전부 기존 것: 예고 원·직선·부채꼴·고리·십자·사각·단일, 시간차 `sweep`, `follow`, `zone`(고리 장판 포함), `summon`, 효과 damage·heal·shield·status(slow·stun·burn·vulnerable·haste·atkDown·root)·pull·knockback(dir). 가로 띠는 `rect dir 'right'/'left' length 24|11`로 그림(`row(y)` 도우미 = 데이터). 속박(root)은 캐릭터에게 걸림(면역은 보스·고정 유닛뿐).

**배율 슬라이더 2개가 패턴에 닿는 방식** (새 규칙이 아니라 디버그 노브, 기본 1 = 아무 변화 없음. 자세히 `docs/boss-raid.md` 4-2):

- 「보스 예고 시간 배율」 ×T: 보스(등급 boss) 스킬의 모든 조각의 `delay`와 `telegraphLead`에 ×T. 한 스킬 안의 조각 간격도 같이 늘거나 줄어듦(예: 역주행 1.4 / 1.75 / 2.1초 × 1.5 → 2.1 / 2.625 / 3.15초). 쿨·첫 시전·연타 간격·장판 시간·기본 공격은 그대로. 보스 자기 시전(M1)의 준비 시간도 같이.
- 「보스 범위 크기 배율」 ×A: 보스 스킬의 모든 조각의 범위에 기존 `scaleArea` 그대로 — 원 반지름, 띠·직선의 길이와 폭, 부채꼴 반지름(각도는 그대로), 십자 길이와 폭, 고리는 **바깥 지름만**(안쪽 구멍은 그대로 → 「안쪽이 안전」한 패턴의 안전 자리는 안 줄어듦), 「한 명」은 변화 없음. 조각의 자리(offset)는 안 바뀜 → 가로·세로 띠는 제자리에서 두꺼워지거나 얇아짐(×1보다 크면 띠끼리 겹치고, 작으면 틈이 생김). 남는 장판도 같은 크기로.
- 둘 다 중형보스·일반 몬스터·캐릭터에는 안 닿음.

**예고 덧그림 4종** (규칙이 아니라 그림): 모양은 기존 예고 그대로, 뜻만 작게 덧그림 — `pull` 안쪽 화살 6개 / `push` 바깥(또는 미는 방향) 화살 / `linger` 사선 빗금(「떨어진 뒤에도 남아요」) / `spawn` 점선 테두리 + 작은 점선 원. 패턴 id → 덧그림 표는 구역 그림 파일의 `<ZONE>_TELE_MOTIF`. 기존 보스 4종에는 넣지 않음(그림 그대로).

- 보스별 `voice` 행(`src/audio/synth/bossVoices/<구역>.ts`): `{ base, motif, timbre, kinds }`. 구역 권장 기본음: 로비 90~135 · 사무실 70~100 · 병동 100~160 · 옥상 45~70 Hz, 같은 구역 안에서 같은 기본음 금지. 음색 토큰 12개: 기존 4(elevator·office·surgery·abyss — 기존 보스 4종, 소리 그대로) + bell·hum·water·static·paper·steps·wind·clatter.
