# 보스 20종 (기획 19차, 2026-10-11)

보스 레이드(`docs/boss-raid.md`)에 나오는 보스 전부. 기존 4종은 수치·그림·소리 그대로(`lore`·`zone`만 추가). 새 16종은 아래 틀을 지킴.

## 1. 공통 틀

- 자리: 맨 위 가운데(12, −1.2) 고정, 반지름 3, 기절·넉백·도발·묶기 면역, 기본 공격 원거리(탄 속도 11, 사거리 40).
- 수치는 1층 기준. HP 6,800~9,200 · 공격 28~32 · 방어 0.2 · 공속 0.5~0.6. 층 배율 × 레이드 HP 배율 0.8이 곱해짐.
- 「피해 2.2」 = 보스 공격력 × 220%. 예고 1.0~1.6초(기존 보스와 같은 띠). 단일 대상 큰 한 방은 저스트 교대 연습용으로 1.4~1.6초.
- 스킬 2~3개 + **페이즈 1개**(HP 45~60%: 이름 + 패턴 1개 추가 + 공속/쿨 배율). 광폭화는 공용 `ENRAGE`(공격 ×1.6 · 공속 ×1.5 · 쿨 ×0.6 · 소환 ×1.5). 그로기 게이지 전부 있음.
- 소리: 패턴마다 kind 하나(기존 12종 doors countdown papers stamp summon blades gas slice burst beam tentacle ring + 새 3종 **water · static · chime**). 보스마다 `voice` (기본음 Hz · 모티프 · 음색 토큰).
- 그림: `src/render/bossart/<구역>.ts`에 코드로. 얼굴·눈은 화면 y 100~230(위 HUD 보스 박스 x 424~856·y<100을 피함), 프레임당 캔버스 호출 ≤ 360, `shadowBlur`·그라데이션·`Math.random` 금지.
