# 궁극기 테스트 모드 (기획 22차)

궁극기를 **어떻게 쓰는지**(조작)를 바꿔 보는 실험 모드. 판 자체는 **보스 레이드 그대로**(20층 · 층마다 보스 · 층 보상 · 그로기 · 「보스 고르기」 디버그). 새 궁극기 조작은 이 모드 안에서만 있고, 클래식 탑 · 원정 · 보스 레이드는 한 글자도 안 바뀜(같은 시드 = 같은 판, 테스트로 확인).

---

## 1. 모드

- 메인 화면 **네 번째 카드 「궁극기 테스트」**(보스 레이드 · 궁극기 조작 실험). 카드 아래: 내 최고 기록 + 마지막으로 고른 방식(「첫 도전 · 방식 조준」).
- 편성 화면 제목 「궁극기 테스트 편성」. 오른쪽 위에 **「궁극기 방식」 상자**(현재 / 조준 / 드래그) — 고르면 이 기기에 기억됨(처음엔 조준). 아래 캐릭터 설명의 궁극기 줄이 고른 방식의 궁극기로 바뀌고 **맨 위**에 보임(폰에서 상자에 밀려 안 가려지게). 전용 설계가 빠진 캐릭터만 「(전용 조준 궁극기 준비 중) …」 + 지금 궁극기 설명(지금은 15명 모두 전용 설계라 안 나옴). 게임 중 카드 길게 누르기(스킬 정보)의 궁극기 줄도 고른 방식의 궁극기.
- 기록은 **따로**(`swap-tower.ultTest.v1`) — 보스 레이드 기록과 안 섞임.
- 멀티: 보스 레이드처럼 「방 만들기」를 하면 **궁극기 테스트 방**(매칭 · 방 목록 · 방 화면에 「궁극기 테스트」 표시). 방에 들어올 때 각자 편성에서 고른 방식을 가져옴(클래식 탑을 고르고 코드로 들어온 사람은 「현재」). **봇 자리는 방장의 방식**(혼자 하기: 내 방식). 방 화면의 자리마다 그 사람의 방식(「궁극기 조준」 …), 빈자리는 「봇 궁극기 …」(방장 방식). 방 안의 「프리셋 변경」은 **방의 모드**를 따름 — 다른 카드로 들어왔거나 새로고침 뒤에 돌아와도 「궁극기 방식」 상자가 보이고, 고른 방식이 방에 그대로 감.
- 층 보상: 「두 번 차는 게이지」 · 「궁극기 여운」은 이 모드에서 안 나옴(지금 궁극기를 다시 쏘는 카드라 시험하는 궁극기와 섞임).
- 게임 중 바꾸기: 디버그 맨 위 **「궁극기 방식」** 단추 3개 → **모든 플레이어(봇 포함)** 의 방식이 바뀜. 멀티는 방장만. 같은 칸에 「궁극기 충전」.
- **「충전」 버튼 (기획 24차, `docs/ult-fx.md` 8-4)**: 궁극기 버튼 오른쪽의 작은 둥근 보라 버튼(「충전」 + 금빛 「+」, 폰 지름 43px). 누르면 **내 세 캐릭터 게이지가 모두 가득**(디버그 「궁극기 충전」과 같은 명령, 성공 알림 없음 — 원호가 차고 「끌기!」 / 「탭!」). 셋 다 가득이면 흐려지고 눌러도 아무것도 안 감(필드만 가득이면 대기 캐릭터를 채우러 누를 수 있음). 궁극기를 겨누는 동안 · 카드를 끄는 동안은 흐리고 못 누름(겨누다 버튼 위에서 떼면 지금처럼 취소, 게이지 그대로). 전투가 아닐 때(보상 · 괴담 방 · 결과) · 관전 중이면 숨음. 궁극기 테스트에서만 만들어짐(클래식 · 원정 · 보스 레이드 화면엔 없음). **멀티는 방장이 아니어도 자기 게이지만** 채움(서버 · 클라이언트 모두 궁극기 테스트 방의 `chargeUlt`만 손님에게 열림, 다른 디버그는 계속 방장만; 프로토콜 8 그대로).

## 2. 세 가지 방식

| 방식 | 궁극기 버튼 | 무엇이 나가나 |
|---|---|---|
| 현재 | 탭 | 지금 궁극기 그대로 |
| 조준 | 누른 채 끌어서 겨눔 → 떼면 발사 | 그 캐릭터의 **조준 궁극기**를 겨눈 곳에 / 겨눈 쪽으로 |
| 드래그 | 버튼을 필드로 끌어 놓음 | 필드 캐릭터가 **그 자리로 순식간에 이동**(번쩍 or 돌진, 착지 연출) → 거기서 **드래그 궁극기** |

- 조준 · 드래그에서도 **짧게 탭하면 지금 궁극기**(이동 없음). 손가락이 버튼 밖으로 한 번도 안 나갔으면 조금 흔들려도 탭(글자 「놓으면 지금 궁극기」).
- 끄는 동안 버튼은 「끌기!」, 위에 「조준」 / 「드래그」 표시. 손가락 위 80px 지점이 겨누는 곳(카드 끌기와 같음 — 손가락이 안 가림).

## 3. 조작 (버튼 제스처)

- 버튼을 누르고 12px 넘게 움직이면 **조준 시작** → 필드에 미리보기가 손가락을 따라옴:
  - 궁극기의 **실제 범위 · 방향**(원 · 고리 · 선 · 부채꼴 · 돌진 길) — 캐릭터 색, 아군만 받는 범위는 연두 점선.
  - 조준: 캐릭터 → 겨눈 곳 점선 + 조준점. 드래그: 이동 화살표(번쩍 = 점선, 돌진 = 실선) + 착지 자리 동그라미.
  - 'target' 부분이 노릴 적에게 테두리.
  - 손가락 바로 아래(46px) 글자: 「놓으면 발사」 / 「놓으면 이동 · 발사」 / 「놓으면 취소」 / 「필드 위에서 놓기」 / 「놓으면 지금 궁극기」 / 못 쓰게 된 이유(「필드에 캐릭터가 없어요」 …). 화면 끝에서도 안 잘리고, 알림(토스트)보다 위에 보임.
  - 조준 거리(`aimRange`) · 드래그 거리 끝이나 보스 몸에 막히면, 점(●)이 **실제로 터지는 / 착지하는 자리**로 옮겨 가고 손가락과 선으로 이어짐.
- **취소**: 버튼 밖으로 나갔다가 버튼 위로 다시 끌고 와서 놓기(빨간 테두리) 또는 필드 밖에서 놓기 → 아무것도 안 나가고 게이지 그대로. 끄는 동안 궁극기를 못 쓰게 되면(캐릭터가 쓰러짐 · 게이지를 다른 데 씀) 놓을 때 「취소됨 · 이유」.
- 미리보기는 게임이 실제로 쓰는 계산과 **같은 것**으로 그림(보이는 곳 = 맞는 곳). 돌진이 벽에 막혀 짧아지면 되돌아 베기 줄도 그만큼 짧게.
- 드래그로 **보스 몸 위에 놓으면** 그 몸 가장자리(이동해 온 쪽)에 착지 — 밀어낼 수 없는 몸(고정 보스 · 걸어다니는 / 무대 보스)만. 방향은 손가락을 놓은 쪽 그대로. 미리보기 고리 = 착지 자리.
- 드래그 궁극기의 컷인은 **작은 배너**(큰 띠가 바로 일어나는 이동 · 착지를 가리지 않게). 번쩍 이동은 캐릭터 색.
- 멀티: 손을 떼는 순간 명령 하나가 감 — `{ type: 'ult', aim: { mode, point, from } }`(`from` = 내 화면에 보이던 필드 캐릭터 자리). 서버가 방식이 맞는지(디버그로 바뀌었으면 「궁극기 방식이 바뀌었어요」), 지점이 숫자인지 확인하고, 지점은 경기장 안으로 당김. **방향 · 조준 거리 · 드래그 거리는 `from`에서 잼**(서버의 진짜 자리에서 2.5칸 안으로 당김) → 걷는 중에 겨눠도 미리보기 방향 그대로. 시전자에서 시작하는 부분과 이동의 출발점은 서버의 진짜 자리. 너무 오래된 화면을 보고 겨눈 명령(2초 넘게)은 교체처럼 취소. **세 화면 모두 같은 자리에서 터짐**(서버가 한 번 계산해서 모두에게 보냄). 다른 사람 화면에는 조준점이 잠깐 보이고(0.8초), 드래그면 착지 연출.

## 4. 대체 규칙 (안전망 — 전용 설계를 지웠을 때만 씀. 지금은 15명 모두 전용 설계, 7장)

전용 조준 / 드래그 궁극기가 없는 캐릭터도 쓸 수 있게, 그때는 **지금 궁극기를 이렇게 바꿔서** 씀 (`src/sim/ultTest.ts`):

**조준**
- **방향형**(네모 · 부채꼴 · 선 · 돌진이 하나라도 있는 궁극기 — 지금 궁극기 중에는 블레이드 천검난무): 시전자 자리는 그대로, **방향만 겨눈 쪽으로 돌림**(첫 방향 부분 기준으로 전부 같이 돌림).
- **범위형**(그 밖): 시전자 주변에 터지던 부분을 **겨눈 곳으로 옮김**(오프셋 모양 그대로 — 팔라딘 창 8개, 퍼펫티어 인형 4개).
- 그대로 두는 것: **자기 강화**(버서커 광란, 워든 보호막, 크로노 쿨 감소 …)와 **아군 전체**(가디언 보호막, 클레릭 은총, 메딕 골든 아워 …).
- 대상을 노리던 부분(레인저 · 메이지 · 거너 · 섀도우): 겨눈 곳에서 **2.5칸 안의 가장 가까운 적**이 대상. 아무도 없으면 겨눈 곳 그 자리.

**드래그**
- 겨눈 곳으로 **번쩍 이동**(최대 **9칸** — 더 멀면 그 방향으로 9칸), 거기서 **지금 궁극기 그대로**. 'target' 부분은 착지 자리 2.5칸 안의 적(없으면 원래 대상).

공통: 겨눈 곳은 경기장 안으로 당김. 이동 · 시전 중 무적 0.5초, 효과는 0.45초부터(컷인 규칙 그대로). 위력은 지금 궁극기와 같음(밸런스 측정 안 함).

**봇**: 조준이면 보스(없으면 자기 대상 → 가장 가까운 적)를 겨눔, 드래그면 보스 바로 앞(자기 쪽)으로 이동 — 이미 그만큼 붙어 있으면 보스 쪽으로 0.3칸(이동 방향 = 드래그 궁극기 방향이 보스를 향하게). 드래그 착지 자리가 안전 구멍 밖 · 적 장판 안 · 곧 떨어질 경고 안이면 기다렸다가 씀(기다리기 시작한 때부터 최대 3초, 그 뒤엔 그냥 씀 — 벤치에서 이미 찬 카드를 막 꺼내도 3초). 전용 설계에 `botAim: 'ally'`면 HP 90% 아래인 가장 다친 아군(없으면 'enemy'처럼), `'self'`면 제자리. 무작위 없음.

### 5-2. 모양

캐릭터 하나 = `{ aim?: 조준 궁극기, drag?: 드래그 궁극기 }`. 각 궁극기는 **지금 궁극기(`CharacterDef.ult`)와 똑같은 모양**(id · name · slot 'ult' · description · castTime · actions)에 세 가지를 더할 수 있음:

- `move` (드래그만): `{ kind: 'dash' | 'blink', maxRange: 칸, path?: { width, affects, effects, delay?, stage? } }` — 이동 방법 · 최대 거리 · 지나간 길에 맞는 공격(선택). 없으면 번쩍 9칸.
- `aimRange` (조준만): 겨눌 수 있는 최대 거리(없으면 어디든).
- `botAim`: 봇이 겨누는 곳 `'enemy'`(기본) · `'ally'` · `'self'`.

액션이 겨눈 곳을 읽는 법:

- `center: 'point'` = **겨눈 곳**(조준) / **착지 자리**(드래그).
- `center: 'self'` = 시전자(드래그는 이미 착지한 자리).
- `center: 'target'` = 겨눈 곳 · 착지 자리에서 2.5칸 안의 가장 가까운 적.
- `rel: 'aim'` = 이 부분의 오프셋 · 네모 / 부채꼴 방향 · 돌진 방향을 **「오른쪽(+x)을 겨눈다」고 치고** 쓰면, 실제 겨눈 쪽으로 돌려서 씀. 조준 = 캐릭터 → 겨눈 곳, 드래그 = 이동한 방향.
- 나머지(delay · hits · zone · summon · dash · charge · follow · stage …)는 다른 스킬과 똑같이 동작.
- `follow`는 정말 따라가야 하는 부분만: 'self' + follow 부분은 그때 시전자가 서 있는 자리에 떨어지는데 미리보기는 시전 자리를 그림 → 멈춘 자리 · 착지 자리에 떨어질 부분은 follow 없이(또는 `center: 'point'`). 반대로 **여러 번 맞는(hits > 1) 'self' 부분은 follow를 붙임** — 없으면 시전자가 교체 · 쓰러졌을 때 남은 타격이 겨눈 곳으로 튐.

규칙: 효과는 `delay: 0.45` 이상(컷인), `castTime: ULT_CAST_TIME`(0.5). id는 `<캐릭터>_ua`(조준) · `<캐릭터>_ud`(드래그).

`stage` 이름 = **소리**: 지금 궁극기 줄의 단계 이름과 같으면 그 소리, 궁극기 줄에 없고 그 캐릭터 **드래그 스킬 줄**에 있으면 그 드래그 소리(거너 slug, 퍼펫티어 toss · thread, 크로노 rift · rewind, 메딕 defib, 워든 hook, 버서커 split …), 둘 다 아니면 역할 기본 소리(`src/audio/director.ts`, `src/audio/stages.ts`). **그림**은 모든 단계가 캐릭터 색의 기본 착지 연출(직선 · 부채꼴은 시작한 자리부터, 아군 전체 부분은 안 그림) + 그룹 파일(5-4)의 추가 연출 — 지금 궁극기의 전용 그림 · 멈춤(히트스톱) · 화면 흔들림은 지금 궁극기 id에만 붙어서 따라오지 않음.

**기획 23차부터 그림 · 손맛 · 소리는 `docs/ult-fx.md`가 정함**(「궁극기 연출 강화」 켬, 기본): 데이터의 `finale` = ★마무리 박자(멈춤 0.13초 · 큰 한자 · 5% 확대 · 숨 고르기 · 바닥 자국), 나머지 박자는 역할(첫 타 · 쌓기 · 짝 · 뒤풀이 · 장판 · 지원 · 길)마다 기본 그림 + 그 궁극기의 이야기(지금 궁극기 그림 재사용 `alias` + 새 그림), 조준 잠금 표시 · 조준선, 드래그 돌진 / 번쩍 · 착지 · 착지 컷, `sfx`(박자 소리 덮어쓰기, 새 파일 없음). 위의 단계 이름 소리 규칙은 `sfx`가 없는 박자에만. 일시정지 「궁극기 연출 강화」를 끄면 이 절의 22차 연출.

### 5-4. 추가 연출 (필요할 때만)

기획 23차부터 새 그림은 **이야기**(`registerUltStories({ '<궁극기>:<단계>': { alias, prep, land, impact, finisher, charge, linger, motif, decor } })`)와 **이동 그림**(`registerUltLooks({ <궁극기>: { move, touchdown, touchdownAt, lock, … } })`)으로 넣음 — 모양 · 도구는 `docs/ult-fx.md` 4-4 · 4-6, 도구는 `src/render/ultTest/kit.ts`에서만 가져옴. 아래 22차 방식(`registerUltFx`)은 「궁극기 연출 강화」를 껐을 때만 불림(그룹 파일의 `if (ULT_FX.boost) return;`).

```ts
// src/render/ultTest/groupA.ts
import { registerUltFx } from './index';
registerUltFx({
  onEvent(ev, view) {
    if (ev.type === 'skillStage' && ev.skillId === 'mage_ua' && ev.stage === 'meteor' && ev.hit === 0) {
      view.host.ring(ev.center.x, ev.center.y, 0.3, 4, 0.5, '#9ad8ff', 4, 0.1);

});
```
`view.host`에 `ring` · `burst` · `flash` · `shake`. `draw(ctx, state, view, now)`로 매 프레임 바닥에 그려도 됨(`view.cam`으로 화면 좌표). 궁극기 테스트가 아닐 때는 불리지 않음.

### 7-2. 고른 안 (두 안을 비교해서 하나를 고르거나 섞음)

캐릭터마다 「그 캐릭터다움」 안과 「조작 맛」 안 두 가지를 만들어 보고 골랐음. 기준: 조준과 드래그가 서로 다른 맛일 것(조준 = 장소 · 방향을 고르는 맛, 드래그 = 지금 드래그 스킬의 강화판), 세 명이 다 돌진하지 않을 것, 보이는 곳 = 맞는 곳.

- 블레이드 조준은 돌진이 아니라 제자리 부채꼴 + 대일섬(버서커 · 섀도우 조준이 이미 돌진).
- 메이지 조준은 지금 블리자드 리듬 그대로(빙벽 안은 퇴마사 조준 벽과 겹쳐서 뺌).
- 레인저 조준의 하늘 화살은 「대상 추적」 대신 겨눈 곳에 떨어짐.
- 섀도우 조준의 분신은 돌진을 시작한 곳 기준(벽에 막혀도 벤 줄 위에서 터짐). 「대상 뒤로 순간이동」 안은 미리보기와 다른 곳에 떨어져서 뺌.
- 클레릭 조준 = 큰 회복 + 끌어모으기, 드래그 = 성역의 종(둘 다 회복 장판이 되지 않게). 메딕 조준 = 디자이너 예시 그대로 「힐장판」. 메딕 제세동은 힐러라 공격력 200% → 150%, 기절 1.2초 → 1초로 낮춤.
- 바드 조준은 띠(아군 버프도 겨눈 쪽으로 감 — 서포터에게도 고르는 맛).
- 크로노 조준의 늪에 아군 공격 속도 +30%를 더함(늪 = 우리 편이 싸울 곳). 크로노 드래그의 정지는 마지막 X자보다 먼저 걸려서 X자 피해도 30% 되돌림에 들어감(24차: 정지 1초 → 되풀이 둘 · ★ 1.65초 시계판도 정지 안이라 30% 되돌림에 들어감).
- 퍼펫티어 드래그 인형은 앞 1.5칸 · 양옆 3칸(보스 바로 앞에 놓으면 보스가 두 인형 사이에 옴). 실은 드래그 스킬 숫자(공격력 40%).
- 가디언 조준은 거리 제한 없음(어디든 던짐), 팔라딘 조준은 9칸 안, 섀도우 조준은 8칸 안(23차 검토: ★초승달이 겨눈 곳에 떨어짐 — 전에는 8칸 돌진이 멈춘 자리라 붙어 있는 보스를 지나쳐 빗나갔음).

### 7-3. 일부러 이렇게 한 것

- 클레릭 · 메딕의 조준 회복은 「모든 아군」이 아니라 **겨눈 곳 주변**(조준의 뜻). 대기 캐릭터 회복 · 부활 단축 같은 전체 효과는 그대로. 봇은 HP 90% 아래인 가장 다친 아군에게(없으면 보스 쪽).
- 레인저 드래그: 봇은 보스 옆으로 뛰어들지 않고 제자리에서 씀(저격수).
- 바드 드래그의 띠는 이동 방향과 상관없이 **세로**(드래그 스킬과 같음). → 24차: 띠 대신 착지 자리 **둥근 무대**(반경 3 · 4.5 · 6 → 피날레 6), 방향 없음.
- 조준에는 'target'(대상) 부분을 안 씀 — 겨눈 곳 근처에 적이 없으면 엉뚱한 적에게 튀기 때문(보이는 곳 = 맞는 곳).
- 따라가는(follow) 부분은 다섯뿐: 버서커 조준 마무리 일격(8.25초에 서 있는 자리), 블레이드 조준 검기 폭풍(블레이드가 서 있는 자리 — 교체 · 쓰러지면 떠난 자리에 남음), 대상을 따라가는 섀도우 드래그 초승달 · 레인저 드래그 연사 · 레인저 드래그 관통 일격(1.25초). (24차: 섀도우 드래그는 먹물 진 · 베기 여섯 · 초승달 모두, 레인저 드래그는 연사 · 포박 · 관통(1.5초) 모두 대상을 따라감.) 미리보기는 시작 자리를 그림. 나머지는 미리보기 자리에 그대로 떨어짐(테스트가 확인).
