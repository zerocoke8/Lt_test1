## 1. 게임 정보라 그림이 바뀌어도 꼭 지킬 것

새 그림체는 자유지만, 아래는 **플레이어가 보고 교대를 결정하는 정보**입니다. 모양 · 크기 · 자리 · 시작/끝 시각을 그대로 두세요. 대부분 코드로 남기는 쪽(9장 (a))이 안전합니다.

### 1-1. 예고(텔레그래프) 모양 = 맞는 자리
- 모양 · 크기 · 자리 = sim 판정 그대로 (`src/sim/geometry.ts` `hitsArea` ↔ `src/render/shapes.ts` `pathArea`). 모양: circle · ring · rect · cross(+ X) · fan · cone · line · single. 바닥 눌림 0.55 그대로.
- 시간: 시전 → 떨어짐 = 부분 `delay` (보스는 × 「보스 예고 시간 배율」). 카운트다운 = 안쪽 복사본이 0 → 1로 자람 (바탕 α 0.24, 카운트다운 α 0.36, `#ff3b3b`), **마지막 0.35초 흰 깜빡** (`src/render/index.ts` 596).
- 저스트 교대 창 = 떨어지기 전 0.5초 (짧은 예고 ×0.6, 최대 0.9초, `src/sim/justSwap.ts`) → 카운트다운이 정확해야 함.
- 겹치면 한 색 (`fillEnemyTelegraphs`, `src/render/index.ts` 452), 여러 부분 공격은 다음 것만 진하게 + 점선 · 번호 · 화살 (`src/render/teleseq.ts`), 흐르는 셰브론, 돌진 화살.
- **적 예고는 어떤 효과 · 컷인 · 충격 프레임에도 가려지지 않음** — 위에 다시 그림 (`drawEnemyDanger`, `src/render/index.ts` 1976).
- 빨강 = 적. **아군 효과 · 바닥 자국에 빨강 금지** (그래서 퇴마사 스킬 범위는 노랑 `AREA_COLOR`, `src/render/look.ts` 256). 밝은 바닥(연필의 종이)에서는 빨간 테두리 밑에 어두운 테두리.
- 아군 예고 · 드래그 / 조준 미리보기 = sim 과 같은 계산 (`src/render/preview.ts`, `src/render/ultTest/preview.ts`) → 「보이는 곳 = 맞는 곳」.

### 1-3. 안전 자리 · 바닥 규칙
- 안전 구멍: 바깥 반경 ≥ 20인 적 고리 → 경기장 전체를 어둡게 하고 구멍만 남김 (`SAFE_RING_OUTER`, `src/render/index.ts` 2149; `drawSafeVeil`, `src/render/bosses/fieldMarks.ts` 242). **구멍 반경은 판정** — 슬라이더로도 안 바뀜.
- 보스 바닥 규칙: 서랍 6칸(각 12×4칸, 번호판 ①–⑤ + 서리 낀 빈 판 = 안전), 「예」(5, 6) · 「아니오」(19, 6) r 3.2 = 안전 원, 에스컬레이터 줄 2.4칸 · 「틈」 y 9.6–12 · 손잡이 띠 x 0–3 / 21–24, 노래방 빛 점 (12, 6) + 빔 6단계 안내, 집게 레일(자기 줄 · 열만 위험), 자리 · 순찰 경로 표시 (`spots`, `move.waypoints`, `src/render/bosses/stage.ts` 111, 139).
- 남는 장판: 그림 = sim 모양. 보스 레이드에서는 캐릭터가 장판 + 0.3칸을 돌아 걸음 (`ZONE_AVOID`, `src/data/bosses/forms.ts` 40) → 그림이 다르면 「아무것도 없는데 피함」으로 보임.
- 돌발 괴담: 엘리베이터 통로 구멍 r 1.5, 비상등 3개 자리, 금색 잠금 고리, 시간 고리.

### 1-5. 누가 누구인지 (판정 원 · 팀 · 역할 · 내 캐릭터)

### 9-4. 효과 그림 규칙
- **바닥 효과는 세로 0.55로 눌림** (고리 · 균열 · 자국 · 마법진 · 그림자). 위에서 본 그림을 눌러 그리거나 처음부터 쿼터뷰로. 서 있는 효과(빛기둥 · 베기 · 별)는 안 눌림.
- **플립북 시계**: 월드 효과 = 레코드 나이 `age / dur` (멈춤 동안 자동으로 멈춤) · 화면층(컷인 · 충격 프레임 · 속도선) = 실제 시계 · 유닛 동작 = `animProgress`.
- **합성**: 지금 가산 합성(`'lighter'`)은 어디에도 안 씀 (새로 쓰면 클래식 해시도 바뀜). 검은 배경 영상은 가산 합성으로, 먹물 · 연기 · 돌 · 먼지 · 구덩이처럼 **어두운 효과는 알파(투명) 스프라이트**가 필요.
- **색**: 대부분 부품이 캐릭터 색(15) · 플레이어 색(3) · 남의 것 세기 `k` 0.55 를 받음 → 흰 / 회색 텍스처를 실행 중에 물들이거나(색마다 캐시) 캐릭터별로 구워 둠. 아군 효과에 빨강 금지.
- **크기**: 텍스처 = 논리 크기 × 2.
- **예산**: 플립북 하나 = 레코드 하나 (1-7). 전체 화면 크기 플립북 · 오프스크린 층은 폰에서 비쌈 (「전체 해상도 층 블릿이 폰 소프트웨어 캔버스에서 약 10 fps를 잃음」, `src/render/index.ts` 450).
- 남의 것 · 봇: 흐리게(k 0.55), 멈춤 · 흔들림 · 확대 · 어둠 · 충격 프레임 없음 — 이 규칙은 코드 그대로.

## 11. 이름 규칙 · 폴더 (제안)

**폴더 · 이름 · 시트 형식 · 스위치는 인계 문서 4-5 ~ 4-7 · 5장 「파일 두는 곳」이 정본**: 원본 `art/raw/` (장비 원본 `art/gear/`, `scripts/art-gear.mjs:8`), 고른 프레임 목록 `art/clips/*.json`, 게임용 `src/assets/art/**` = WebP 1장 + JSON hash 1개, 프롬프트 `scripts/art-prompts/*.json`, 스위치 「그림: 코드 / 새 그림」. 이 장은 id 목록과 동작 이름만 정리.

지금 있는 두 칸과 같은 방식: 장비 `src/assets/gear/<name>.png` (고정 이름 목록 + 없으면 코드 그림), 소리 `src/audio/files/<id>.mp3` (없으면 합성음).

```
src/assets/art/
  units/<defId>.*            캐릭터 15 · 아군 소환물 turret paper_doll rw_shade rw_duet rw_doppel rw_turret rw_mine
                             · 몬스터 slime … red_mask (copy_mini 는 copy_man 재사용 가능)
                             · 중형 ogre lich elevator_girl copier_beast head_nurse signal_man
                             · 소환 · 돌발 prize_doll lost_sock bed_decoy fe_toad fe_printer fe_shadow fe_patient fe_child
                             동작(animations 키) = idle move attack cast appear stunned (sim 이름) + hit death ult dash blink (렌더 전용)
  bosses/<bossId>.*          포즈 = idle walk windup attack groggy (BossPose), 보는 방향 side front back (예 walk-front)
                             고정 6의 부품 · 단서 층 <bossId>-part-<이름> (예 dead_monitor-part-cursor), 그로기 판
  stage/<bossId>-p<phase>.webp       보스 바닥 8 (+ 2페이즈)
  zones/<theme>-<normal|boss>[-rift<n>].webp   + 덧그림
  portraits/<charId>.webp            초상 (컷인 상반신은 <charId>-bust, 제안)
  fx/<name>.*                Fx 이름 소문자 (slash, xslash, spin, star, muzzle, pillar …), 파티클 pk-<name>, 바닥 자국 decal-<kind>
  ui/<묶음>/<id>.webp         pet role status tag trace event room frame menu
src/assets/gear/<name>.png   지금 칸 그대로 (52 이름 고정)
src/audio/files/<id>.mp3     그대로
```

- **id는 코드 id 그대로** (캐릭터 · 몬스터 · 보스 · 펫 · 구역 · 방 · 흔적 · 이벤트 · 상태 · 태그 · 유물). 데이터 id를 바꾸면 소리 id도 바뀌므로 id는 바꾸지 않음.
- 그림은 **오른쪽 보기**, 발 중앙 기준점. 시트 `meta` 예 (제안): `"pivot": [96, 176], "scale": 0.5, "source": "codex+seedance"`, 동작마다 `"clock": "progress", "hitFrame": 2, "loop": false`. `clock` = `progress`(유닛 동작, `animProgress`) / `world`(효과, 멈춤 때 같이 멈춤) / `real`(화면층). `source` = 만든 도구 · 프롬프트 (소리의 `generated.json` 처럼).
- 칸 동작은 장비 칸을 따라 하기: ① 데이터에서 만드는 고정 이름 목록 + 목록 밖 이름 경고 ② `import.meta.glob` ③ 파일이 없거나 안 풀렸으면 코드 그림 (하나씩 바꿔 넣으며 비교) ④ 「그림: 코드 / 새 그림」 스위치 (지금 「장비 그림: 코드 / 파일」 처럼) ⑤ 크기 예산 테스트 ⑥ 줄이는 스크립트 (Chromium 경로는 고칠 것).
- **원본 영상 · 큰 원본은 커밋하지 않음** (`art/raw/`). 커밋은 줄인 시트 + JSON + 프롬프트 + `art/clips/*.json` 만.
