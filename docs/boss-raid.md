# 보스 레이드 모드 (기획 19차, 2026-10-11)

보스 20종의 표·외형·새 규칙은 `docs/bosses.md`. 결정 요약은 `docs/game-design.md` §32.

## 1. 한 줄 요약

클래식 탑과 똑같은 흐름(층 → 보상 → 다음 층)인데 **1층부터 20층까지 전부 보스층**. 보스 20종(기존 4 + 새 16)이 **한 판에 한 번씩** 나오고, 5층마다 구역 배경이 바뀜(로비·상가 → 사무실 → 폐병동 → 옥상·이계). 솔로(봇 2명, 아티팩트 빌드)와 3인 멀티에서 같이 됨.

## 2. 흐름

1. 메인 화면 세 번째 카드 「보스 레이드」 → 프리셋 → 매칭 화면(클래식과 같은 화면, 위에 「보스 레이드」 칩).
2. 「혼자 하기」 = 봇 2명과 바로 시작. 「방 만들기」 = 보스 레이드 방(방 목록에 「보스 레이드」 태그). 방·재접속·방장 넘김은 클래식 방과 완전히 같음.
3. 층 시작 배너: 「N층 · 보스 이름」 + 괴담 한 줄. 보스를 쓰러뜨리면(HP 0 → 퇴각) 「보스 퇴각! N층 돌파 · 보스 N/20」.
4. 층 사이: 층 보상 1장(3장 중) — 5·10·15·20층은 유물 화면. 괴담 방은 클래식 스케줄 그대로.
5. 20층 보스 퇴각 → 승리. 전멸 → 패배. 결과 화면에 「보스 레이드 N층」과 내 최고 기록.

## 3. 20층 구성과 순서

- 층 f의 구역 = ⌈f/5⌉번째 구역. 1~5 로비·상가 · 6~10 사무실 · 11~15 폐병동 · 16~20 옥상·이계. 배경·층 시작 음은 그 구역 것.
- 구역마다 보스 5종(기존 1 + 새 4). 고정 표 `ZONE_BOSSES` (`src/data/bosses/index.ts`):

| 구역 | 보스 5종 (id) | 등장 구간 |
|---|---|---|
| 로비·상가 | 인형 뽑기 기계 `claw_machine` · 혼자 도는 세탁기 `washer_drum` · 지하 7번 노래방 `karaoke_room` · 거꾸로 가는 에스컬레이터 `reverse_escalator` · 닫히지 않는 엘리베이터 `elevator_keeper`(기존) | 앞 · 앞 · 중 · 뒤 · 뒤 |
| 사무실 | 문서 파쇄기 `shredder_maw` · 식지 않는 커피 머신 `coffee_machine` · 퇴근 못 한 모니터 `dead_monitor` · 끝나지 않는 회의 `endless_meeting` · 야근의 군주 `overtime_lord`(기존) | 앞 · 앞 · 중 · 뒤 · 뒤 |
| 폐병동 | 번호 없는 서랍 `morgue_drawers` · 투시 촬영기 `xray_machine` · 멈추지 않는 제세동기 `defibrillator` · 빈 병상 행렬 `empty_beds` · 수술실 원장 `surgeon_director`(기존) | 앞 · 중 · 중 · 뒤 · 뒤 |
| 옥상·이계 | 물탱크의 주인 `tank_dweller` · 천둥 안테나 `thunder_antenna` · 대답하는 연필 `answering_pencil` · 거꾸로 뜬 달 `inverted_moon` · 심연의 감시자 `abyss_watcher`(기존, **20층 고정**) | 앞 · 앞 · 중 · 뒤 · 최종 |

- **순서는 시드로 정해짐** (`src/sim/bossRaid.ts bossRaidOrder(seed)`): 구역마다 `mixSeed(seed, 0xb055, 구역번호)` 스트림으로 5종을 섞음. 두 가지 손질:
  1. 옥상은 「심연의 감시자」를 빼고 4종만 섞어 16~19층에 두고, **20층은 항상 심연의 감시자**(최종 보스).
  2. 구역 첫 층(1·6·11·16층)에 「뒤」 구간 보스가 오면, 뒤가 아닌 첫 보스와 자리를 바꿈 → 구역의 첫 보스는 늘 앞·중 구간.
- 런 rng(`w.rng`)는 쓰지 않음 → 같은 시드 = 같은 순서, 서버·HUD·결과 화면 누구나 다시 계산 가능. 디버그로 20층을 넘기면 21층부터 같은 순서 반복.
- 아레나: 보스 아레나 24×12, 보스는 맨 위 가운데(12, −1.2) 고정, 반지름 3. 시작 위치 = 클래식 보스층과 같음.
- 플랜에 `nextBossId`(다음 층 보스)가 실려 소리 미리 굽기(`warmBoss`)가 그걸 읽음.

## 4. 난이도 · 광폭화 · 그로기

- 층 배율은 **클래식 `floorStatMult(f)` 그대로**(1층 1.00 · 5층 1.48 · 10층 2.28 · 15층 3.08 · 20층 3.87). 파티도 층마다 보상 1장을 받으니 성장 곡선이 클래식과 같음.
- 레이드 전용 노브 `BOSS_RAID.hpMult = 0.8` (보스 HP에만 곱함, `FloorPlan.bossHpMult` 자리 재사용). 공격은 그대로(`atkMult 1`).
  - 근거: 클래식 보스전 중앙값 80~90초 × 0.8 ≈ 65~72초/보스 → 20마리 ≈ 23분 + 보상·괴담 화면 2~3분 ≈ **25분**. 벤치 뒤 0.75~0.9 사이에서 다시 맞춤.
- 새 보스의 1층 기준 HP 띠: 로비 8,200~9,000 · 사무실 8,400~9,200 · 폐병동 6,800~8,000 · 옥상 7,000~8,200(기존 보스와 같은 띠; 자기 회복이 있는 제세동기는 6,800으로 미리 깎음).
- 광폭화: 층마다 `bossFloorTime`(90초) 뒤, 클래식 보스층과 같음(공격 ×1.6 · 공속 ×1.5 · 쿨 ×0.6 · 소환 ×1.5). 광폭화 뒤 필드가 30초 비면 패배(기존 규칙).
- 그로기: 20종 전부 게이지 보유(배수 0.8~1.1, 표 참고). 사람 수 배율·반복 상승 등 기존 규칙 그대로.
- 기절 면역, HP 0 = 퇴각 = 층 클리어, 보스 페이즈(한 번만) 기존과 같음.

## 5. 보상 · 유물 · 괴담

- **층 보상**: 매 층 클리어 → 3장 중 1장(기본 1 + 신규 2 + 교대 태그 카드, 다시 뽑기, 지명권 전부 그대로). 전설은 클래식처럼 11층부터.
- **유물**: 5·10·15·20층 클리어 때만 클래식 보스층과 똑같이 **유물 화면**(일반 보상 없음). 1~4층 같은 보스층은 일반 보상.
- **다시 뽑기 +1**: 5·10·15·20층 클리어 때만(클래식 「보스마다 +1」을 그대로 두면 4층에 이미 최대 5개).
- **괴담 방**: 클래식 스케줄 그대로(구역마다 1개, 2~4 / 7~9 / 12~14 / 17~19층 중 시드가 고른 층 — `goedamSchedule`이 5의 배수 층을 이미 뺌, 코드 변경 없음).
- **돌발 괴담**: 없음(보스 플랜에서는 원래 안 뜸).
- 층 회복 20%, 전멸한 플레이어의 다음 층 부활, 궁극기 환불 등 기존 규칙 그대로.
- `#보스` 태그 보상이 매 층 효과를 내므로 벤치에서 그 비중을 따로 적음(필요하면 레이드에서만 값을 낮추는 것은 벤치 뒤 결정).

## 6. 멀티 · 봇

- 방에 `variant: 'classic' | 'bossRaid'`. 원정의 `RoomMode`(목록 숨김, 나가기=탈퇴)는 쓰지 않음 — 레이드 방은 클래식 방과 같은 생명주기.
- 프로토콜 5 → 6: `createRoom.mode?`, `RoomInfo.mode?`, `RoomSummary.mode?`, `start.mode: 'expedition' | 'bossRaid'`. 스냅샷의 `state.mode`로 HUD·결과가 모드를 읽음.
- 코드로 들어갈 때 모드가 달라도 **참가 허용**, 방 화면 이름 옆에 「보스 레이드」 태그만.
- 봇 행동 변경 없음(저스트 3%, 보상은 `botPickIndex`). 「거꾸로 뜬 달」의 모이기 패턴에 봇이 늘 맞는 것은 감수(봇 사망은 클리어율에 작게만 반영).
- 멀티 보상 타이머 30초 그대로.

## 7. 화면

- 메인: 세 번째 카드 「보스 레이드」 — 부제 「20층 · 층마다 보스 · 보스 20종」, 발 「최고 기록 N층 · 클리어 N회」(없으면 「첫 도전」). 마지막에 고른 모드로 강조.
- 매칭/방: 위 칩 「보스 레이드」, 방 목록 줄 태그, 방 화면 이름 옆 태그.
- HUD: 보스 박스 왼쪽 레벨 자리 → 「N층」, 이름 옆 작은 알약 「보스 N/20」. 층 시작 배너 「N층 · 보스 이름」 + 괴담 한 줄(`lore`). 보스에 걸린 자기 버프(보호막·가속·취약·회복 준비)는 보스 박스 아래 작은 아이콘 줄(이미 있으면 그대로).
- 일시정지 제목 「N층 · 보스 레이드」. 디버그 「층 건너뛰기」 라벨이 레이드에서는 「다음 보스로」(같은 skipFloor), 「광폭화」·「전멸」 그대로.
- 결과: 제목 옆 「보스 레이드」 칩, 「도달 층 N층 · 보스 N/20」, 「쓰러뜨린 보스 N마리」, 「내 최고 기록 N층」, 층별 시간 칩은 「N층 · 보스 이름」. 승리 문구 「보스 20종을 모두 쓰러뜨렸어요」.

## 8. 저장

- 내 기기 localStorage `swap-tower.bossRaid.v1` = `{ bestFloor, clears, runs }`. 솔로·멀티 모두 **내가 도달한 층**을 저장(구분 없음). 메인 카드 발과 결과 화면이 읽음.
- 마지막 모드 기억(`saveMode`)에 `'bossRaid'` 추가.

## 9. 밸런스 목표와 재는 법

| 목표 | 수치 |
|---|---|
| 보스 1마리 | 중앙값 60~90초, p90 ≤ 120초 |
| 런 길이 | 20~25분(전투 합 + 보상 화면 추정 7초/층) |
| 20층 클리어율 | 직접 교대(active) 40~60%, 봇만(bot) 20~35% |
| 광폭화 비율 | 층마다 ≤ 30% |
| 급사(한 패턴에 캐릭터 사망) | 어느 보스도 사망의 40%를 넘지 않음 |

- 벤치 `npm run bench:raid` = `tests/review/boss-raid-bench.ts` → `critic-20f.ts`를 `MODE=bossRaid`로 돌려 층별 표(보스 id · 클리어율 · 중앙값/p90 초 · 광폭화 % · 그로기 횟수 · 전멸 수), 런 총 분, 보스별 평균 시간(순서가 섞이므로 층이 아니라 **보스별**로 모음), `#보스` 태그 보상 비중을 출력. 노브: `RUNS`(기본 240) · `POLICY=active|bot` · `SEED0` · `RAID_HP`(hpMult 덮어쓰기) · `BOSS=<id>`(그 보스만 1~20층에 반복 — 한 마리 튠용) · `OUT`(JSON 저장 경로).
- 튠 순서: ① `RAID_HP`로 전체 길이 맞추기(0.75~0.9) → ② 보스별 평균 시간이 띠 밖이면 그 보스 HP ±10% → ③ 급사가 많은 패턴은 피해 −0.2 또는 예고 +0.2초 → ④ 회복 보스(제세동기)가 길면 회복 6 → 4%.
- 클래식 탑은 `planFloor` 미수정 → 골든 해시 변경 없음을 테스트로 지킴.

## 10. 구현 순서

1. **CORE**(혼자 먼저): 모드 종류·플랜 빌더·프로토콜 6·서버 variant·등록소 4개(보스 데이터 `src/data/bosses/`, 보스 그림 `src/render/bossart/`, 보스 소리 `src/audio/synth/bossVoices/`, 예고 모티프)·새 규칙 4개 확인·벤치 뼈대·단위/네트 테스트·디버그 라벨. 기존 보스 4종은 구역 파일로 옮기고 수치·그림·소리 그대로.
2. **병렬**: 보스 콘텐츠 4트랙(로비 / 사무실 / 폐병동 / 옥상 — 각자 데이터·그림·소리·테스트 파일 4개만) + UI 트랙(메인 카드·방 태그·HUD·결과·저장·e2e·스크린샷).
3. **통합**: 전체 검사, 벤치(RUNS=240 active|bot) → `hpMult`·보스별 HP 재조정, e2e 폰/데스크톱/멀티, 스크린샷 눈으로 확인, 독립 리뷰, 수정, `docs/game-design.md` §32 채움, 아티팩트 다시 빌드.

## 11. 기획 확인 (테스트 뒤 물을 것)

1. 20층 보스를 「심연의 감시자」로 고정한 것 — 매 판 마지막 보스가 달라지는 쪽이 좋으면 한 줄로 풀 수 있음. (추천: 고정)
2. 레이드 HP 배율 0.8(한 마리 65~72초, 런 약 25분)로 시작 — 더 짧은 런(20분)이 좋으면 0.7. (추천: 벤치 뒤 0.75~0.9 안에서)
3. 5·10·15·20층은 유물만(일반 보상 없음) — 둘 다 주면 성장이 클래식보다 빨라짐. (추천: 유물만)
4. 새 소리 종류 3개(water·static·chime)와 보스별 처치음 — 더 필요한지 들어 보고. (추천: 이대로)
5. 새 보스 16종의 이름·괴담 한 줄(`docs/bosses.md`) — 바꿀 번호가 있으면 알려 주기. (추천: 이대로)
6. 「거꾸로 뜬 달」 월식(불린 사람 2.6칸 안만 안전)에 봇이 늘 맞는 것 — 봇에게 「월식 예고 중 대상 옆으로 교대」 한 줄을 넣을지. (추천: 벤치에서 봇 사망이 눈에 띄면 넣기)
