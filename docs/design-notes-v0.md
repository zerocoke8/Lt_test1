# 게임 기획 정리 v0 (프로토 착수 전)

> 2026-10-04 · 아직 확정 전 초안. 질문 번호로 답하면 반영 예정.

## 기획 정리

### 개요 / 플랫폼
- 목적: 기획을 정리하고 프로토타입을 제작함
- 플랫폼: 스마트폰, 인게임은 **가로(landscape)** 화면
- 장르 골격(요약): **캐릭터 3명 교체형 자동전투(플레이어당 필드에 1명) + 로그라이크 탑 오르기**. 필드에는 **플레이어 3명**(나 + 봇 2명)이 있음

### 파티 구성 & 교체
- 플레이어 1명이 전투에 **캐릭터 3명**을 데려감
- **1번 캐릭터가 필드에 나와 있는 상태로 시작**
- 필드에서는 **현재 선택된 1명만** 싸움
- 교체: 좌하단에 있는 **다른 캐릭터의 얼굴 카드**를 필드로 드래그해서 놓음 → 기존 캐릭터가 사라짐 → 새 캐릭터가 **드래그스킬을 쓰면서 등장**

### 전투 & 스킬
- 전투는 **자동**이고 **주변 타겟을 우선 공격**함. 정확한 규칙은 Q5
- 캐릭터마다 스킬 5종

| 스킬 | 발동 조건 | 설명 |
|---|---|---|
| 기본평타 | 자동전투 중 반복 | 주변 타겟 우선 |
| 패시브 | 상시 적용 (해석) | 효과와 적용 조건 미정 → Q20 |
| 일반스킬 | 쿨타임 있음 | 자동 시전인지 수동인지 미정 → Q4 |
| 드래그스킬 | 카드를 드래그해 등장할 때 | 교체 등장 연출을 겸함 |
| 궁극기 | 게이지가 가득 찬 뒤 플레이어가 누름 | 그 순간 필드에 있는 캐릭터가 사용 |

### 궁극기
- 게이지는 **화면 가운데쯤**에 있고 **시간이 지나면 참**
- 가득 차면 **플레이어가 눌러서 발동**하고, 그때 필드에 있는 캐릭터가 사용함
- 게이지를 누가 갖는지(내 캐릭터 3명 공용 / 캐릭터별 / 플레이어 3명 공용)와 교체해도 유지되는지는 미정 → Q8

### 멀티플레이
- 멀티플레이 예정이라 프로토 필드에 **다른 플레이어 봇 2명**이 같이 있음 (필드 위 플레이어 총 3명)
- 협동인지 경쟁인지(Q15), 실시간인지 비동기인지(P2)는 언급 없음

### 진행 구조 (탑)
- 로그라이크 방식으로 **탑을 오름**. 판마다 무엇이 바뀌는지, 탑이 몇 층인지, 실패하면 어떻게 되는지는 미정 → Q14
- **5층마다 보스** (5, 10, 15층…)
- 그 외 층: **중형 보스와 일반 몬스터 여러 마리**가 **주기적으로 여기저기서 등장**. 중형보스가 층당 1마리인지, 주기적으로 여러 마리 나오는지는 미정 → Q12
- UI 레퍼런스로 기존 게임 스크린샷을 받음. 어디까지 가져올지는 미정

### A. 프로토 범위 (P0: 프로토 착수 전 필수)

**1. 검증할 핵심 가설 & 일정**: 이번 프로토로 증명하려는 재미 1가지는 무엇이고, 쓸 수 있는 기간은 얼마인가요?
제안: A) 교체의 손맛(언제, 누구를, 어디에 넣고 궁극기는 언제 쓸지) / B) 5층 런을 또 하고 싶어지는지 / C) 3인 멀티의 재미 → **추천: A가 1순위. v0(1주): 층 1개 + 교체·궁극기 + 봇 2명. v1(2~3주): 5층 런 + 보스 + 층 보상. v0 플레이테스트 결과를 보고 v1 진행 여부를 판단.**

**2. 제작 주체 & 엔진**: 누가 어떤 엔진으로 만드나요? 프로토 코드를 본편에서 다시 쓰나요?
제안: A) 웹(TypeScript + Phaser/Three.js). 폰 브라우저에서 URL로 바로 테스트할 수 있고, 버리는 코드가 전제 / B) Unity / C) Godot → **추천: 본편 엔진이 정해져 있으면 그 엔진, 아니면 A.**

**3. 콘텐츠 최소량 & 캐릭터 역할**: 탱커/딜러/서포터나 근접/원거리 같은 역할 구분이 있나요? 프로토에 캐릭터·몬스터·층을 몇 개 넣나요?
제안: A) 캐릭터 3명(근접 탱커, 원거리 딜러, 서포터) + 일반몹 2종 + 중형보스 1 + 보스 1, 1~5층 / B) 캐릭터 6명 + 일반몹 3~4종 + 중형보스 2 / C) 층 1개짜리 무한 웨이브 → **추천: v0는 C, v1은 A. 봇도 같은 캐릭터 풀을 씀.**

### B. 조작 & 전투 규칙 (P0)

**4. 플레이어 입력 범위 & 우하단 버튼**: 이동도 완전 자동인가요? 일반스킬은 쿨이 돌면 자동으로 나가나요? 레퍼런스에는 조이스틱이 없지만, 우하단에 쿨다운('99s')이 도는 카드 2장과 빈 슬롯이 있어 수동 버튼으로 보입니다. 이 자리를 쓸 계획인가요? 쓴다면 무엇인가요?
제안: A) 이동·평타·일반스킬 모두 자동. 입력은 교체 드래그와 궁극기 탭뿐(우하단 없음) / B) A + 우하단 수동 버튼(일반스킬 수동 시전, 또는 소환·아이템) / C) A + 탭으로 이동 지시 → **추천: v0는 A로 하고 우하단 자리는 비워 둠. 우하단 버튼이 무엇인지 알려 주시면 v1에서 B로 추가. 원거리 캐릭터 AI는 '사거리 안에 들어오면 멈춰서 공격'까지만.**

**5. '주변 타겟 우선'의 정확한 규칙**: ① 공격할 때마다 가장 가까운 적을 다시 고르나요, 한 적을 계속 노리나요? ② '주변'의 탐지 반경은 얼마인가요? 반경 안에 적이 없으면 맵에서 가장 가까운 적에게 가나요, 제자리에서 대기하나요? ③ 보스·중형보스와 잡몹 사이에 우선순위가 있나요? ④ 반대로 몬스터는 플레이어 3명 중 누구를 노리나요?
제안: A) 공격할 때마다 가장 가까운 적을 다시 선택 / B) 가장 가까운 적을 고정하고, 죽거나 사거리 밖으로 나가면 다시 선택 / C) 거리와 몬스터 종류 가중치를 합친 점수제 → **추천: B. 반경 안에 적이 없으면 맵 전체에서 가장 가까운 적에게 이동. 종류별 가중치는 데이터로 열어 두고 초기값 0. 일반몹은 가장 가까운 플레이어를 노리고, 보스는 주기적으로 타겟을 바꿈.**

**6. 카드를 놓는 위치의 의미 & 필드 캐릭터 재드래그**: 카드를 놓은 지점이 등장 위치나 드래그스킬 조준점이 되나요? (위치가 상관없다면 드래그보다 탭이 편합니다.) 지금 필드에 있는 캐릭터를 다시 드래그해서 위치를 옮기거나 드래그스킬을 다시 쓸 수 있나요? 이동 조작이 없는 구조라서, 허용하면 유일한 위치 조정 수단이자 악용 포인트가 됩니다.
제안(위치): A) 놓은 지점에 등장하고 그 지점에서 드래그스킬 발동 / B) 기존 캐릭터 자리에 등장하고, 놓은 지점은 스킬 조준에만 사용 / C) 위치 무관
제안(재드래그): A) 불가 / B) 위치 이동만 허용(쿨 적용, 스킬 없음) / C) 교체와 똑같이 처리
→ **추천: 위치는 A(드래그스킬은 놓은 지점 중심의 원형 범위로 통일해서 시작). 재드래그는 A(원문이 '다른 캐릭터' 카드만 언급하므로). 보스 패턴을 피할 수단이 부족하면 B를 시험.**

**7. 교체 제한 방식 & 드래그스킬 쿨**: 레퍼런스에서 보이는 단서는 다음과 같습니다.
① 카드 위 칸이 '교체불가' 카드에만 없음
② '교체가능' 카드의 마름모에서 '0.99'가 카운트되고 있음
③ '교체불가' 카드의 마름모 타이머는 돌지 않고 있음

①~③을 합치면 교체 가능 여부는 칸(자원)으로 정해지고, 마름모 타이머(드래그스킬 쿨?)는 따로 움직이는 것처럼 보입니다. 확인하고 싶은 점은 다음과 같습니다.
- 교체 제한은 시간 쿨인가요, 자원 소모인가요, 둘 다인가요?
- 제한은 모든 카드에 공통으로 걸리나요, 캐릭터마다 따로인가요?
- 청록 칸과 빨강 칸은 각각 무엇인가요?
- 교체는 되는데 드래그스킬 쿨이 아직 남아 있으면 어떻게 되나요?

제안(제한): A) 시간 쿨(짧은 공통 쿨 + 캐릭터별 재등장 쿨) / B) 자원 소모(교체 1회에 칸 1개, 시간이 지나면 회복) / C) A + B
제안(드래그스킬 쿨 중에 교체할 때): A) 스킬 없이 등장 / B) 교체 자체를 막음 / C) 약화된 스킬로 등장
→ **추천: 칸의 의미를 알려 주시기 전까지는 제한 A(공통 1~2초 + 재등장 10~15초, 죽은 캐릭터는 교체불가). 드래그스킬 쿨은 레퍼런스처럼 교체 쿨과 분리하고, 쿨 중에 교체하면 A(스킬 없이 등장).**

**8. 궁극기 게이지의 소유 단위·충전·발동**: 게이지는 내 캐릭터 3명이 함께 쓰는 1개인가요, 캐릭터마다 따로인가요, 플레이어 3명이 공유하는 팀 게이지인가요? 교체해도 유지되나요? 시간 말고 적중·처치·피격으로도 차나요? 무엇을 눌러서 발동하나요?
제안: A) 플레이어당 1개(내 캐릭터 3명 공용), 교체해도 유지 / B) 캐릭터별 게이지 / C) 팀 공용(플레이어 3명이 1개를 공유, 누가 누를지 규칙이 필요) → **추천: A + 시간으로만 충전 + 가득 차면 쓸 때까지 대기. 중앙 원형 게이지를 직접 탭해서 발동하고, 게이지 안에 지금 필드에 있는 캐릭터의 궁극기 아이콘을 표시.**

**9. HP 단위 & 필드 캐릭터 사망 처리**: HP는 캐릭터마다 따로인가요? 필드 캐릭터가 죽으면 자동으로 교체되나요, 플레이어가 드래그할 때까지 기다리나요? 이때나 게임·층을 시작할 때도 드래그스킬이 나가나요?
제안: A) 다음 캐릭터가 바로 자동 등장(스킬 없음) / B) 살아 있는 카드의 교체 제한을 풀어 주고 3초 안에 드래그하게 함(스킬 발동). 시간이 지나면 자동 등장 / C) 드래그할 때까지 필드를 비워 둠 → **추천: 캐릭터별 HP + B. 자동 등장할 때와 게임·층 시작 때는 드래그스킬 없이 등장.**

**10. 플레이어 전멸 & 부활**: 한 플레이어의 캐릭터 3명이 모두 죽으면 어떻게 되나요? 런 실패는 플레이어 3명이 모두 전멸했을 때인가요, 한 명이라도 전멸했을 때인가요?
제안: A) 전멸한 플레이어는 관전하다가 층을 클리어하면 HP 30%로 부활, 3명 모두 전멸하면 실패 / B) 15초 뒤 캐릭터 1명이 자동 부활 / C) 한 명이라도 전멸하면 실패 → **추천: A. 봇도 같은 규칙을 따름.**

### C. 탑 진행 (P0)
