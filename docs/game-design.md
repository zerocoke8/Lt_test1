# 게임 기획서 (프로토 기준)

> 2026-10-04 · 1차 질문 답변 반영본
>
> 표기: ✅ 확정 · 🔶 추천안 채택 (답변이 "추천") · (해석) 원문을 이렇게 이해함 · ❓ 미정 (14장 질문 참고)

---

## 1. 개요

- **플랫폼**: 스마트폰 가로 화면. 프로토는 **웹**으로 만듦 ✅
- **장르**: 캐릭터 3명을 교체하며 싸우는 자동전투 + 로그라이크 탑 오르기
- **멀티**: 필드에 플레이어 3명 (나 + 봇 2명). 완전 협동 ✅
- **프로토 목표**: **교체의 손맛** 검증 ✅
- **프로토 범위**: **5층 런 + 보스 + 층 보상** ✅

## 2. 편성 (프리셋)

- 던전에 들어가기 전에 **프리셋 설정에서 캐릭터 3명을 골라** 데려감 ✅
- 캐릭터에는 **역할 구분**이 있음 ✅ (역할 종류 ❓ Q6)
- 펫도 프리셋에서 고르는지 ❓ Q5

## 3. 필드와 카메라

- 기본 **쿼터뷰** ✅
- 맵이 좌우로 넓으면 **카메라가 캐릭터를 따라감** ✅ (내 필드 캐릭터 기준 (해석))
- **이동은 완전 자동** ✅

## 4. 캐릭터 교체

- **1번 캐릭터가 필드에 나와 있는 상태로 시작** ✅
- 좌하단에 **카드 3장이 모두 보이고, 활성 카드만 크게** 표시 ✅
- 대기 카드를 필드로 드래그해서 놓으면 ✅
  1. 기존 캐릭터가 사라짐
  2. **놓은 지점에** 새 캐릭터가 등장
  3. 그 자리에서 **드래그스킬** 사용
- **드래그하는 동안 드래그스킬 범위를 보여 줌** ✅
- 필드에 있는 캐릭터를 다시 드래그할 수 없음 ✅
- **교체 제한 = 시간 쿨** ✅
  - 캐릭터마다 **재등장 쿨 8~12초**. 드래그스킬이 강할수록 길어짐 ✅
  - **재등장 쿨이 곧 드래그스킬 쿨**이고, 드래그스킬 쿨은 따로 없음 ✅
  - 카드에 보이는 숫자(레퍼런스의 '99')는 **교체 가능까지 남은 시간** ✅
  - 쿨은 등장한 순간(드래그스킬을 쓴 순간)부터 돎 (해석, ❓ Q4)

## 5. 펫

- 우하단 슬롯. **캐릭터와 별개** ✅
- 펫 카드를 필드로 드래그해서 놓으면 **펫의 기능이 발동** ✅
- **교체가 아님**: 필드 캐릭터는 그대로 있음 ✅
- 레퍼런스: 슬롯 3칸, 쿨다운 표시('99s')
- 펫 수, 기능 종류, 쿨, 지속 방식 ❓ Q5

## 6. 전투와 타겟팅

### 6-1. 타겟팅 규칙 ✅

1. **가장 가까운 적**을 타겟으로 잡음. 몬스터 종류(보스·중형보스·일반몹)에 따른 **예외 없음**
2. 한번 잡은 타겟은 **죽을 때까지 계속 노림**
3. 주변에 적이 없으면 **맵에 있는 적을 찾아 이동**. 맵에도 없으면 **제자리에서 대기**
4. **몬스터도 같은 규칙**으로 가장 가까운 대상을 공격
5. 몬스터가 노리던 캐릭터가 교체로 사라지면 **다시 가장 가까운 대상**을 찾음

### 6-2. 스킬 5종

| 스킬 | 발동 | 비고 |
|---|---|---|
| 기본평타 | 자동 | 6-1 타겟팅 규칙 |
| 패시브 | 상시 | 필드에 있을 때만, 본인에게만 적용 🔶 |
| 일반스킬 | 쿨이 돌면 자동 시전 | 이동이 완전 자동이라 일반스킬도 자동 (해석) |
| 드래그스킬 | 교체해서 등장할 때 | 놓은 지점 중심. 쿨 = 재등장 쿨 8~12초 |
| 궁극기 | 공용 게이지가 가득 찼을 때 탭 | 그때 필드에 있는 캐릭터가 사용 |

- 스킬 효과 대상(본인 / 내 파티 / 모든 아군)은 **스킬마다 데이터로 지정** 🔶
- 스킬 조준 기준은 **스킬마다 데이터로 지정** (대부분 현재 타겟이나 자기 중심) 🔶
- 궁극기 컷인은 **내 화면에만**, 게임은 멈추지 않음 🔶

## 7. 궁극기 게이지

- **공용** 게이지 ✅ (내 캐릭터 3명 공용인지, 플레이어 3명 공용인지 ❓ Q1)
- **시간으로만** 충전 ✅
- 가득 차면 화면 가운데 원형 게이지를 탭해서 발동, 필드 캐릭터가 사용 ✅

## 8. HP, 사망, 부활

- HP는 **캐릭터마다 따로** ✅
- 필드 캐릭터가 죽으면 ✅
  - **30초 뒤 부활**
  - 자동으로 나오는 캐릭터 없음. 유저가 **다른 캐릭터를 직접 드래그해서** 꺼내야 함
  - 그동안 내 필드는 비어 있음
- **모두 죽으면 사망** ✅ (누가 모두 죽는 건지, 사망하면 어떻게 되는지 ❓ Q2)
- 부활한 캐릭터의 HP ❓ Q2
- 대기 중에는 쿨만 돌고 HP 회복은 없음 🔶
- 내려간 캐릭터가 깔아 둔 장판·소환물·도트는 남고, 자기 버프는 내려갈 때 해제 🔶

## 9. 탑 구조

- **프로토: 1~4층 일반층 + 5층 보스층** ✅ (5층마다 보스)
- **층을 넘어갈 때 모든 상태가 이어짐** ✅ (HP, 사망·부활 대기, 궁극기 게이지, 쿨, 버프)
- **층을 클리어하면 HP 20% 회복** ✅
- **층 제한시간**: 우상단 타이머. **시간이 다 되면 끝** ✅ (런 실패로 해석, ❓ Q3)

### 9-1. 일반층 (1~4층)

- 중형보스와 일반몹이 맵 여기저기서 **주기적으로 등장**하지만, **계속 나오지는 않음** ✅
- **몬스터를 다 잡으면 클리어** ✅
- 스폰 수치 🔶 (1차 추천안을 '총량 고정'에 맞춰 조정)
  - 층마다 정해진 웨이브 수
  - 웨이브 간격 8초, 웨이브당 일반몹 4~6마리
  - 동시에 최대 30마리
  - 가장자리 스폰 지점 6~8곳 중 랜덤
  - 스폰 1초 전 바닥 마커 표시
  - 중형보스는 층당 1마리 (2종 중 하나)
  - 웨이브 수와 중형보스 등장 시점 ❓ Q7

### 9-2. 보스층 (5층)

- 보스는 **잡을 수 없음** ✅
- 패턴으로 **잡몹 소환**과 **광역공격** ✅
- **클리어 조건** ❓ Q3

## 10. 층 보상 (로그라이크 요소)

- 층을 올라갈 때마다 **랜덤으로 제시되는 능력치·기능 중에서 고름**. **레어도** 있음 ✅
- 일반층 보상: **스탯이나 스킬** ✅
- 보스층 보상: **유물** ✅
- 제시 개수, 레어도 단계·확률, 적용 대상 ❓ Q8

## 11. 멀티와 봇

- **완전 협동**. 결과창에 **기여도** 표시 (딜량, 받은 피해, 처치 수) ✅
- 봇 🔶
  - 플레이어와 같은 규칙: 캐릭터 3명, 교체, 드래그스킬, 궁극기
  - HP 30% 이하가 되면 바로 교체, 그 외에는 20~30초마다 교체
  - 궁극기는 가득 차면 0.5~3초 랜덤으로 늦춰서 사용 (3명이 동시에 쓰는 것 방지)
  - 편성은 고정 프리셋, 스탯은 플레이어와 같음, 같은 캐릭터 중복 허용
  - 펫 사용 여부 ❓ Q5

## 12. 프로토 콘텐츠

|---|---|---|
| 캐릭터 | 역할 구분 있음. 프리셋에서 3명 선택 | 풀 크기·역할 ❓ Q6 |
| 일반몹 | 5종 | ✅ |

## 14. 추가 질문

1차 답변을 반영하면서 새로 생긴 질문이에요. 번호로 답해 주시면 돼요.

**Q1. 궁극기 '공용'의 범위**: 내 캐릭터 3명이 함께 쓰는 게이지인가요(플레이어마다 1개), 플레이어 3명이 함께 쓰는 팀 게이지인가요?
→ 추천: 플레이어마다 1개, 내 캐릭터 3명 공용.

**Q2. '모두 죽으면 사망'의 범위**
- 내 캐릭터 3명이 모두 죽으면 나만 사망인가요, 플레이어 3명이 모두 전멸해야 사망인가요?
- 나만 사망했을 때 봇이 층을 클리어하면 다음 층에서 돌아오나요?
- 30초 뒤 부활한 캐릭터는 HP가 얼마인가요?

→ 추천: 내 캐릭터 3명이 동시에 죽어 있으면 나는 관전. 플레이어 3명 모두 그 상태가 되면 런 실패. 층을 클리어하면 관전 중인 플레이어도 복귀. 부활 HP는 50%.

**Q3. 보스층 클리어 조건**: 보스를 잡을 수 없다면 보스층은 어떻게 끝나나요? 상단 보스 HP바는 무엇을 보여 주나요?
- A) 제한시간 동안 버티면 클리어. 보스 HP바는 깎이긴 하지만 0이 되지 않음(딜량 측정용, 기여도에 반영)
- B) 소환된 잡몹을 일정 수 처치하면 클리어
- C) 보스에게 일정량의 피해를 주면 보스가 퇴각하며 클리어

→ 추천: A. 이때 일반층 타이머가 끝나면 실패, 보스층 타이머가 끝나면 클리어로 구분.

**Q4. 재등장 쿨의 시작 시점과 시작 상태**
- 쿨은 등장한 순간부터 도나요, 필드에서 내려간 순간부터 도나요?
- 게임을 시작할 때 2·3번 카드는 바로 교체할 수 있나요?
- 아무 카드나 교체한 직후에 다른 카드까지 잠그는 공통 쿨이 있나요?

→ 추천: 쿨은 등장 순간부터. 시작할 때 2·3번은 바로 교체 가능. 공통 쿨 없음(대신 등장 연출 0.5초 동안은 교체 불가).

**Q5. 펫 상세**
- 플레이어당 몇 마리인가요? (레퍼런스는 슬롯 3칸)
- 프리셋에서 고르나요?
- 기능은 즉발 효과(힐, 광역 피해, 버프)인가요, 일정 시간 필드에 남는 소환물인가요?
- 쿨은 어느 정도인가요?
- 드래그할 때 캐릭터처럼 효과 범위를 보여 주나요?
- 봇도 펫을 쓰나요?

→ 추천: 프로토는 펫 2마리(슬롯은 3칸, 1칸 비움). 프리셋에서 선택. 즉발형 1종 + 소환형 1종. 쿨 30~60초. 드래그 중 범위 표시. 봇도 쿨이 돌면 사용.

**Q6. 캐릭터 풀과 역할**
- 프로토에서 고를 수 있는 캐릭터는 몇 명인가요?
- 역할은 무엇 무엇인가요? (예: 탱커 / 근접딜러 / 원거리딜러 / 서포터)
- 프리셋에 역할 제약이 있나요? (예: 같은 역할 중복 불가)

→ 추천: 역할 4종 × 1~2명 = 캐릭터 5~6명. 역할 제약 없음.

**Q7. 일반층 웨이브 구성**
- 층마다 웨이브가 몇 번 나오나요?
- 중형보스는 언제 등장하나요? (마지막 웨이브 / 일정 처치 수 이후)
- 층이 올라갈수록 무엇이 늘어나나요? (몹 수, 몹 종류, 스탯)

→ 추천: 1층 3웨이브에서 시작해 층마다 1웨이브씩 증가. 중형보스는 마지막 웨이브에 등장. 층당 몬스터 스탯 +12%.

**Q8. 층 보상 상세**
- 보상을 몇 개 보여 주고 1개를 고르나요?
- 레어도는 몇 단계이고 확률은 어떻게 되나요?
- 보상은 내 캐릭터 3명에게 다 적용되나요, 한 명을 골라서 적용하나요? (스킬 강화는 특정 캐릭터 대상일 가능성이 높음)
- **유물은 5층 보스를 깬 다음에 나오는데, 프로토 런은 5층에서 끝나요.** 유물을 프로토에서 어떻게 검증할까요?

→ 추천
- 3개 제시, 1개 선택.
- 레어도는 일반 / 희귀 / 영웅 3단계, 확률 70 / 25 / 5%.
- 스탯은 파티 전체에 적용하고, 스킬 강화는 해당 캐릭터에 적용.
- 유물은 프로토 런을 6~7층까지 늘려서 보스를 깬 뒤에 효과를 체감하게 하거나, 1층 시작 전에 유물 1개를 고르게 하는 방식 중 선택.

**Q9. 카드의 아이콘**: 카드 오른쪽 방패 아이콘과 왼쪽 마름모 아이콘('0.99' 표시)은 무엇인가요?
→ 추천: 방패는 역할 아이콘, 마름모는 프로토에서 제외.

## 15. 프로토 메모 / 리스크

- **교체 쿨이 재미를 거의 다 결정함**
  - 입력이 교체, 궁극기, 펫 세 가지뿐임.
  - 재등장 쿨 8~12초에 캐릭터 3명이면 3~4초마다 교체할 수 있음.
  - 너무 바쁘면 쿨을 늘리고, 너무 한가하면 줄여야 함. **재등장 쿨, 궁극기 충전 속도, 봇 화력 배율을 실시간으로 조절하는 디버그 슬라이더**를 첫 빌드부터 넣기.
- **'타겟 고정 + 예외 없음'의 부작용**
  - 근접 캐릭터가 중형보스를 물면 끝까지 그것만 침. 그동안 잡몹이 원거리 아군을 공격해도 반응하지 않음.
  - 의도한 동작이라면 그대로 두되, 플레이테스트에서 답답함이 나오는지 볼 것.
  - 교체로 등장 위치를 고르는 게 사실상 타겟을 바꾸는 수단이 됨(놓은 지점에서 가장 가까운 적을 새로 잡음). 이것이 '교체 손맛'의 핵심 재미가 될 수 있음.
- **필드가 빈 상태**
  - 필드 캐릭터가 죽고 남은 카드가 모두 쿨 중이면 내 필드가 비게 됨.
  - 이때 몬스터는 다른 플레이어를 노림. 화면에 "교체 가능까지 N초"를 크게 보여 주기.
- **봇 구조**
  - 봇을 따로 만든 NPC로 고정하지 않음.
  - 플레이어 슬롯 하나에 조작 주체(내 터치 / AI / 나중에 네트워크)만 바꿔 끼우는 구조로 만들어 멀티 전환에 대비.
  - 입력은 명령 데이터로 처리하고, 로직과 연출을 분리하고, 고정 틱과 시드 랜덤을 사용.
- **가로 조작과 가독성**
  - 카드를 끄는 손가락이 착지 지점을 가림. 드래그스킬 범위 표시를 손가락보다 위에 띄우기.
  - 좌하단은 OS 제스처나 노치와 겹치기 쉬움.
  - 3명이 동시에 궁극기를 쓰고 몹 30마리가 있는 상황의 프레임을 측정하기.
- **데이터 구조**
  - 스킬 5종과 펫 기능을 '발동 조건 + 조준 + 효과' 템플릿 하나로 정의.
  - 캐릭터 / 스킬 / 펫 / 몬스터 / 층 / 보상 테이블은 JSON으로 관리.
- **디버그 기능**: 층 점프, 궁극기 즉시 충전, 무적, 쿨 해제, 게임 속도 조절.
- **레퍼런스 리소스 미사용**: 레퍼런스 게임의 이미지와 UI 리소스는 임시로도 쓰지 않음.
